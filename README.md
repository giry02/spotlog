# Spotlog Hybrid

Spotlog는 국내 랜드마크 영상을 발견의 입구로 사용하고, 사용자가 다녀온 여러 여행을 날짜별 동선과 장소 이야기로 남겨 공유하는 모바일 우선 여행일기 서비스입니다.

## 현재 구조

Spotlog의 본체는 모바일웹이고 Expo 앱은 네이티브 기능이 필요할 때만 개입하는 하이브리드 셸입니다.

| 영역 | 담당 |
|---|---|
| `web/` | 국내 랜드마크 영상, 다중 여행, 공개 여행일기, 날짜별 지도·동선, 장소 공유 등 모바일웹 UI |
| `src/hybrid/HybridShell.tsx` | 모바일웹 로딩, 연결 오류 처리, 웹 메시지 수신 |
| `shared/hybridBridge.ts` | 웹과 앱이 주고받는 메시지 계약 |
| Expo 네이티브 | OS 공유 시트와 향후 카메라·위치·알림·딥링크 |

웹 브라우저에서는 웹 공유 API 또는 클립보드로 동작합니다. 같은 웹을 Expo WebView에서 열면 공유 요청이 브리지를 거쳐 Android·iOS 네이티브 공유 시트를 호출합니다.

이전 React Native 전용 화면은 `src/screens/` 등에 프로토타입 참고용으로 남아 있지만 현재 `App.tsx` 진입점에서는 사용하지 않습니다.

## 실행

처음 한 번 의존성을 설치합니다.

```bash
npm install
```

기본 실행은 모바일웹입니다. 다음 명령을 실행하면 개발 서버를 시작하고 브라우저를 엽니다.

```bash
npm start
```

브라우저에서는 `http://localhost:5173`으로 확인할 수 있습니다.

브라우저를 자동으로 열지 않으려면 `npm run web`을 사용합니다.

터미널 2에서 Expo 앱을 실행합니다.

```bash
npm run android
# 또는 macOS에서
npm run ios
```

Expo 개발 서버만 먼저 열고 싶다면 `npm run app`을 사용합니다.

Android 에뮬레이터는 기본적으로 `http://10.0.2.2:5173`, iOS 시뮬레이터는 `http://localhost:5173`을 불러옵니다. 실제 휴대폰에서는 컴퓨터와 같은 Wi-Fi에 연결한 뒤 컴퓨터의 LAN 주소를 지정합니다.

```powershell
$env:EXPO_PUBLIC_SPOTLOG_WEB_URL='http://192.168.0.10:5173'
npm run android
```

운영 빌드에서는 배포된 HTTPS 모바일웹 주소를 `EXPO_PUBLIC_SPOTLOG_WEB_URL`로 지정합니다.

## 현재 데모 범위

- 국내 랜드마크만 노출하는 실제 MP4 자동재생 쇼츠 피드
- `localStorage` 기반 복수 여행 생성·보관
- 계획 중 여행과 발행한 공개 여행일기 목록
- 여행기 제목·소개·날짜·본문을 직접 쓰는 블록 편집기
- 글 사이에 휴대폰 사진을 넣고 설명을 붙이거나 순서를 바꾸는 기능
- 랜드마크·숙소·맛집·카페를 직접 등록하거나 준비된 목록에서 골라 카드로 삽입하는 기능
- 다른 여행자의 공개 가이드를 내 비공개 여행으로 복사한 뒤 독립적으로 수정하는 기능
- `바람을 따라 걷는 제주 서쪽` 완성형 샘플: 주변 풍경·음식·관찰 사진과 장소별 장점·아쉬운 점을 담은 2박 3일 여행 에세이
- 여행별 소개글, 날짜별 이야기, 본문 속 장소 기록
- 실제 좌표 기반 MapLibre·OpenStreetMap 지도와 OSRM 도로 동선·번호 마커·이동 애니메이션·구간별 예상 이동시간·거리
- 장소별 도착 시각과 체류시간을 편집하고 다음 장소까지의 일정 여유·충돌을 확인하는 기능
- 내 여행 상세에서 확인 후 여행기를 영구 삭제하는 기능
- 숙소·맛집·카페를 포함한 모든 장소의 개별 공유와 카카오맵 길찾기
- 전체 여행일기의 브라우저 공유 또는 Expo 네이티브 공유 브리지
- WebView 연결 상태와 오류·재시도 화면

현재 여행기 편집과 복사는 브라우저 `localStorage`에서 실제 동작합니다. 선택한 사진은 모바일 크기로 축소해 데모 데이터에 함께 저장합니다. 좌표가 있는 장소는 OSRM 공개 데모 서버에서 도로 경로와 예상 이동시간·거리를 받아오며, 실패하면 직선거리 기반 예상치로 자동 전환합니다. 이 값은 실시간 교통을 반영하지 않으므로 정확한 출발 시점의 소요시간은 카카오맵 길찾기에서 다시 확인해야 합니다. 운영 단계에서는 공개 데모 서버 대신 자체 라우팅 서버나 상용 길찾기 API를 연결하고, 여러 장의 원본 사진을 위한 오브젝트 스토리지 업로드와 회원 서버 동기화도 추가해야 합니다. 직접 입력한 장소는 주소로 카카오맵 검색을 엽니다.

현재 피드 영상은 UI 검증을 위한 Cloudinary 공개 데모 자산입니다. 운영 전에는 Spotlog 콘텐츠 저장소와 스트리밍 CDN URL로 교체해야 하며, 장소 데이터의 `video` 필드만 바꾸면 됩니다.

## 프로젝트 원칙

- 모바일웹이 서비스 UI와 비즈니스 흐름의 기본 실행 환경입니다.
- Expo 앱은 기기 권한과 OS 기능이 필요한 경계만 담당합니다.
- HotelNGo와 회원·저장소·런타임을 공유하지 않습니다.
- PMS 또는 HotelNGo를 직접 참조하지 않습니다.
- 가격·재고·예약·정산은 Spotlog 1차 범위가 아닙니다.
- 숙소와 업체는 가격·예약 상품이 아니라 여행일기 속 공유 가능한 장소로 다룹니다.
- 공개 여행기 복사는 원본을 수정하지 않고 출처를 보존한 새 비공개 초안을 만듭니다.
- 향후 예약 연결이 필요해질 때만 독립 API 어댑터로 HotelNGo를 선택 연동합니다.
