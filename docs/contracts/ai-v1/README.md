# AI·백엔드 협업 묶음 · v1 초안

2026-10-05 정리 · 로컬 작업 · 실서비스 연결 전

**기본 경로는 맥미니 소형 로컬 LLM의 조건 해석과 승인된 내부 자료 검색이다.** 근거가 충분한 모델 실패 부분만 외부 대형으로 보완하며, Jev는 선택적인 비교 후보다. 화면은 현재의 간단 생성 유지. 이 묶음은 협의 가능한 첫 계약이며 실제 서버 구현·AI 성능 검증 완료를 뜻하지 않는다.

|---|---|
| [연결 계약](CONTRACT.md) | 화면 ↔ 서버 ↔ 맥미니 역할, 입력·초안·저장·실패 처리 |
| [판별 기준](CLASSIFICATION.md) | 기본값·직접 선택·원문 충돌, 음식·숙박·추가 요구 처리 |

| [한국어 시험 100개](cases.ko.jsonl) | 입력·예상 정답·다음 처리·보존할 원문 |

2026-10-05 생성기를 실행해 위 5개 생성 파일을 저장했다. 기계 규격과 public/internal 요청·응답의 JSON Schema 검사를 통과했다. 이 형식 검사는 모델을 실행하거나 실제 검색·일정 품질을 측정하지 않는다. 과거 README의 `frontend-fixtures.json`, `frontend-fixtures.mjs`, `validate.py`, `evaluate.py`, `VALIDATION.md`는 이 작업본에 제공되지 않으므로 완료 산출물·실행 명령으로 안내하지 않는다.

## 바로 나눠서 할 일

| 담당 | 시작 작업 | 끝났다는 기준 |
|---|---|---|
| 백엔드 개발자 | 계약 검토 → 회원 권한·placeId·자료 버전 → 초안/저장 API | 샘플 요청에 같은 구조 응답, 타인 자료·오래된 저장 차단 |
| 사용자 / AI 담당 | 맥미니에 묶음 복사 → 기존 Flowise 확인 → 소형 로컬 해석 시험 → 필요 시 Jev 비교 | 100개 실제 결과 파일·오답 목록·전체 생성 시간 확보 |
| 함께 | 지역 1곳의 사용 허가된 장소 자료 선정 | 랜드마크·식당·숙박·좌표·출처를 실제 검수한 30~50곳 |
| 프론트 | 검증된 서버 어댑터 연결 | 입력 보존·DAY/식사 순서·실패 안내·최종 저장 확인 |

지역 자료 수집과 맥미니 설치는 이번 묶음에 포함되지 않음. 시험 카탈로그의 `fixture-*` 장소는 가상 자료이며 운영 DB로 옮기지 않음.

## 오프라인 검사

저장소 루트에서 실행한다. 생성기는 Python 표준 라이브러리만 사용하고 외부 AI를 호출하지 않는다.

```sh
python docs/contracts/ai-v1/build_bundle.py
```

생성 후 `schemas.json`의 `$defs`로 요청·정규화·초안·RAG 샘플을 검사한다. 별도 모델 평가 실행기·현재 화면용 변환기는 구현 전이다. 기존 `AiPlannerAdapter`와 서버 DTO 사이의 변환 작업도 남아 있다.

실제결과 기록 제안: `{"id":"KO-001","prediction":정규화결과객체,"latencyMs":실측전체시간,"stageMs":{"classification":실측시간},"run":{"path":"local-small","model":"실제모델버전","concurrency":1,"warm":true}}`. 선택적 Jev 비교는 별도 경로 이름으로 기록한다. 실패한 요청도 `prediction:null`, `error:"timeout"` 등으로 남긴다. 시간 미측정 시 필드를 생략한다. 예상 정답을 복사한 파일은 성능 결과가 아니다.

개발용 70개·보류 평가용 30개로 구분. 같은 묶음의 보류 문장은 간단한 누수 방지용이며, 출시 전에는 새 고객 표현으로 별도 블라인드 평가 필요. 모델·프롬프트 수정 후 보류 정답으로 반복 튜닝하지 않음.

## 협의 후 고정할 값

- 1~7일·최대 랜드마크 30곳/전체 방문 60개: 현재 프론트 범위에 맞춘 v1 한도.
- 음식 기본 포함·카페 요청 시 포함·2일 이상 숙박 포함: 현 샘플 동작을 기준으로 한 **초기 정책 제안**, 고객에게 새로 확정받은 정책 아님.
- API 경로·시간 제한·모델 선택·정확도 목표는 구현 시 합의할 값. 비용·속도 보장 없음. 외부 대형 보완은 요청 전체 최대 1회이며 시간·비용 한도 없이 활성화하지 않음.
- UI 직접 선택 출처, 서버 revision, 구조화된 부분 결과: 프론트 연결 시 추가 작업. 현 로컬 검증기를 그대로 서버 정답 판정기로 쓰지 않음.
