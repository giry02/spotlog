# 공공 관광자료 기반 여행 샘플 · 출처 및 이용 기록

확인일: **2026-09-10**  
적용 범위: `web/src/publicTourismContent.ts`, `assets/spotlog/public-tourism/`  
공개·배포 범위: 최초 작성은 로컬 작업임. 2026-09-11 사용자가 문서와 여행기 메뉴의 AI 추천 샘플4개·사진11개·출처 표시를 선택 공개하도록 승인함. 홈 AI 생성·담기 재설계·갤러리 등 다른 로컬 기능은 이번 공개에 포함하지 않음.

## 1. 무엇을 만들었는가

기존 여행기를 복제하거나 방문 후기를 꾸며 쓰지 않고, 공식 관광 안내와 사용 조건을 확인한 실제 사진으로 **편집형 추천 일정 4개**를 구성함. 작성자는 `Spotlog 공공자료 가이드`로 표시함.

| 여행 | 기간 | DAY별 장소 | 고유 장소 수 |
|---|---|---|---:|
| 숲길에서 백사장으로, 해운대의 하루 | 당일치기 | 동백섬 → 해운대해수욕장 | 2 |
| 부산의 골목과 시장, 바다로 이어지는 이틀 | 1박 2일 | 감천문화마을 → 국제시장 / 자갈치시장 → 광안리해수욕장 | 4 |
| 골목·해안길·해변으로 보는 부산 3일 | 2박 3일 | 감천문화마을 → 국제시장 → 자갈치시장 / 이기대 → 광안리 / 동백섬 → 해운대 | 7 |
| 고분의 초록과 연못의 빛, 경주 이틀 | 1박 2일 | 대릉원 → 첨성대 / 월정교 → 동궁과 월지 | 4 |

- 전체 고유 장소 11개, 실제 사진 11개. 동일 장소의 사진은 여러 일정에서 재사용함.
- 여행기 화면의 `AI 추천 여행` 분류에 사용함. 데이터는 `recommendationKind: 'AI'`, `recommendationBasis: 'OFFICIAL_SOURCE_SAMPLE'`로 구분함.
- 외부 LLM을 호출한 실시간 생성 결과가 아님. 본문에도 **공공자료를 편집한 샘플**임을 명시함.
- 실제 사용자 방문, 평가, 인기 순위, 저장 수, 조회 수를 만들어내지 않음. 신규 샘플 집계 초기값은 0임.
- 날짜·교통편·숙박·실시간 영업시간은 미확정임. 날짜는 `날짜 미정`, 체류 시간은 `권장`으로 표시함. 임의의 호텔·음식점이나 가짜 후기 사진을 채워 넣지 않음.
- 관광지 소개 사실은 출처를 참고하고 문장은 새로 작성함. 개인적인 체험이나 기관의 Spotlog 추천·보증인 것처럼 표현하지 않음.

## 2. 이용 조건 판단

**공공기관 자료라고 저작권이 없는 것은 아님.** 이번에 사용한 것은 개별 이미지 게시물 또는 이미지가 포함된 특정 저작물에 `공공누리 제1유형: 출처표시`가 명시된 자료임. 다른 이미지나 해당 사이트 전체에 이 조건이 적용된다고 확대 해석하지 않음.

- 공공누리 제1유형: 출처표시 조건으로 상업적 이용과 변경 이용을 허용하는 유형임. [공식 이용조건](https://www.kogl.or.kr/info/licenseType1.do)
- 사진마다 소유 기관·표기된 저작자·원본 게시물 링크·유형을 보존함. 화면의 사진 출처 링크와 `getPublicTourismSource(image)`가 이를 연결함.
- 부산관광아카이브는 **각 개별 사진의 상세 게시물**에 표시된 제1유형을 확인함. 별도 원본 다운로드 신청이나 로그인 우회 없이 본문에 공개된 중간 크기 사진을 사용함.
- 동백섬은 **부산시 갈맷길의 `[2-1코스] 동백섬2` 개별 갤러리 게시물**에 표시된 제1유형을 확인함.
- 경주는 **`경주 시내권 핵심 바이블`이라는 특정 코스 저작물**의 제1유형 표시와 그 본문에 실제 배치된 네 사진을 확인함. 사이트의 일반 저작권 안내만 보고 가져온 것이 아님.
- 공공누리는 제3자 초상권·상표권 등 모든 권리를 자동으로 해소하는 제도가 아님. 사진 속 사람이나 상인을 광고 모델·추천인처럼 사용하지 않음. 개인정보·초상권 이의가 접수되면 개별 사진을 교체·제외할 수 있도록 출처를 유지함.
- 당초 자료는 변경 없이 다운로드함. 후속 기술 최적화로 크기·포맷을 변경한다면 변경 내역과 원본 출처를 유지해야 함.

### 사진 출처 표시 방식 — 2026-09-10 확정

- 사진 가까이에 짧은 **‘사진 출처’ 버튼**을 두고, 누르면 기존 하단 팝업에서 원문 제목·소유 기관·표기된 저작자·제작/게시 시점·라이선스·확인일·원문 및 이용 조건 링크를 확인함. 여행기 하단은 ‘사진 출처 / N개 자료’ 행으로 전체 자료 목록을 제공함.
- 캡션은 장면 설명에 사용하고 출처 메타데이터와 분리함. 새 샘플 생성 시 `사진: 부산광역시 · 공공누리 제1유형` 같은 문구를 캡션에 다시 붙이지 않음. 사진 출처 버튼과 상세 정보는 유지함.
- 이미 저장된 사용자 기록은 덮어쓰지 않음. 알려진 공공자료 샘플의 출처 접미문구만 연결된 메타데이터와 대조하여 읽기 화면의 중복 표시를 정리함. 사용자가 작성한 설명·확인되지 않은 출처 표기는 임의 삭제하지 않음.
- AI·담기 하단 팝업 안에서는 같은 패널에서 출처를 확인하고 돌아옴. 작성 내용·DAY·포함/제외·스크롤 상태를 보존함. 카드 전체가 버튼인 곳은 중첩 버튼을 만들지 않고 기존 비대화형 출처를 보존함.
- 후속 여러 사진 갤러리는 활성 사진의 출처와 함께 전환함. 여행 복사·번역·공유 때도 사진 ID와 출처 연결을 보존하며, 비대화형 인쇄·이미지/PDF 내보내기는 실제 출처 문구·원문 주소 또는 출처 목록을 출력해야 함. 갤러리·내보내기 완성 여부와 출처 표시 기준을 구분함.
- 버튼으로 표시하더라도 개별 자료의 이용 조건 확인은 생략하지 않음. 이 표시 방식이 모든 자료에 대한 이용 허락이나 법적 안전을 보장한다는 뜻은 아님. 수급·저장 규격은 [데이터 수급안 6절](DATA_SUPPLY_AND_NAVER_PLAN.md#6-장소사진권리-데이터-규격)을 따름.

### 사진과 일정 표현의 구분

- 감천: 실제 마을 전경을 사용함. 주민의 생활 공간이므로 관람·촬영 배려를 안내함. 방문 시간이나 출입 정책이 바뀔 수 있어 특정 운영 시각을 단정하지 않음.
- 국제·자갈치: 실제 시장 사진을 사용함. 특정 업소를 인기 음식점으로 추정하지 않음. 과거 사진이므로 오늘의 영업 상태·가격을 뜻하지 않음.
- 광안리: 실제 해변·광안대교 사진을 사용함. 드론쇼 등의 행사를 방문일에 볼 수 있다고 가정하지 않음.
- 해운대: 행사 시기 항공 전경임을 캡션에 표시함. 현재 행사나 해수욕 가능 여부와 혼동하지 않도록 함.
- 이기대: 사진은 구름다리 야간 전경이나 추천 일정은 **낮 산책**임을 명시함. 사진만 보고 야간 개방이나 안전을 보장하지 않음.
- 동백섬: 해안 보행로와 해운대 방향 풍경을 사용함. 유모차·휠체어 접근 가능한 구간은 현재 안내를 별도 확인하도록 함.

## 6. 제외한 자료와 남은 운영 과제

- 공공누리 제4유형으로 표시된 사진은 상업적 사용·변경 제한 때문에 사용하지 않음.
- 한국관광공사 사진 자료 중 별도 이용 신청·1회 이용 등 추가 조건을 확정하지 못한 자료는 사용하지 않음. 사진별 제1유형 마크만 보고 별도 조건을 무시하지 않음.
- 로그인·다운로드 신청이 필요한 원본은 우회해서 가져오지 않음.
- 사진별 장소·촬영자를 정확히 대응하기 어려운 공모전 묶음도 제외함.
- 제주·서울 등 다른 지역은 장소와 개별 사진 사용 조건을 확인한 뒤 확대함. 지역 수를 맞추기 위해 다른 지역 사진을 대체 사용하지 않음.
- 운영 공개 전에는 사진별 출처 표시가 카드·여행기·사진 피드·저장·복사본·AI 결과에서도 유지되는지 확인해야 함.
- 사용자 데이터에 저장한 이미지 URL이 배포 때 바뀌는 경우를 대비해 장기적으로 사진 ID와 출처 메타데이터를 함께 저장하는 구조가 필요함. 현재는 번들 이미지 URL의 정확한 매칭과 `getPublicTourismSource(image)`로 연결함. 캡션 안의 반복 출처 문구를 유일한 출처 기록으로 사용하지 않음.
- 본 데이터의 여행 생성은 일정 편집 예시이지 검증된 실시간 경로·인기 추천 엔진이 아님. 후속 서버 연동에서는 실제 교통·영업 데이터와 별도로 출처·라이선스 상태를 관리해야 함.
