# 가입·약관·위치 동의 검수본 · 2026.10.08

**후속 정정:** 아래 내용은 먼저 만든 약관 검수본의 이력. Google/Apple만 제공한다는 해석은 사용자 요청과 달랐음. 일반 이메일 가입·로그인을 복원하고 전역 세션/비로그인 화면을 추가함. 현재 기준은 [계정 상태 정정 보고](ACCOUNT_STATE_CORRECTION_20261008.md)와 [수정 계약](../contracts/account-v1/README.md). 정책 문서는 draft-2로 갱신. 아래 draft-1/소셜 전용 화면·22검사 결과를 최신 상태로 전달하지 않음.

사용자 요청: 약관 작성·동의 체크 구현, Google·Apple 두 로그인 방식, 향후 내 위치 기준 서비스 반영. 운영 주체·주소·이메일은 ‘미정’으로 확인됨. 로컬 검수본 반영이며 실제 회원 인증·GPS 검색 연결·Git/공개 사이트 배포는 하지 않음.

## 약관에 포함한 범위

회원 식별 항목과 목적·기간·거부 영향, 선택 항목 구분, 개인 일정과 공개 여행기, 업로드 권리, 신고·운영 조치, AI 초안 확인·승인, 개인 자료의 공용 RAG 자동 편입 제외, 삭제·휴지통6개월과 회원 정보 보관 기간 구분, 외부 지도·AI·파일·로그인 연결, 국외 처리 확정 항목, 위치 동의·기기 권한·철회 구분.

운영자 정보와 실제 업체·국가·보존 기간은 미정 표시. 문서 버전 `2026-10-08.draft-1`, 초안 상태. 가입 체크는 현재 화면 상태이며 실제 동의 증빙으로 저장하지 않음. 위치 설명을 열거나 동의를 체크해도 현재 GPS·기기 권한 요청 없음.

향후 내 위치 서비스는 기능 선택 → 목적·약관 동의 → 기기 권한 → 1회 위치 사용 순서. `LocationConsentPanel`과 `requestCurrentLocation`에 준비. 정식 공개 문서·연결 활성화·일치하는 동의 버전·기능 콜백이 없으면 실행 불가. 단말 권한 거부·잘못된 좌표·시간 초과·취소 처리, 늦은 콜백 반영 방지. 지속/백그라운드 추적과 위치 저장은 추가하지 않음.

## 연결 계약과 남은 부분

[계정 API·DTO 계약](../contracts/account-v1/README.md)과 [응답·동의 샘플](../contracts/account-v1/fixtures.json) 작성. 기존 이메일 어댑터는 이전 호환 검사용이며 새 고객 화면은 `socialAccountService.ts` 사용.

실제 연결에 필요한 작업:

- Google/Apple 개발자 등록, 서버 코드 교환·토큰 검증·callback·회원 DB·보안 세션.
- 동의 항목·문서 버전·서버 기록 시각·철회 이력 저장, 최신 약관 재검증, 회원별 자료·권한 관리.
- callback 후 가입 화면 자동 재개, 고객 화면 전역 회원 상태와 기기 자료의 명시적 가져오기. 현재 로컬 여행을 계정에 자동 병합하지 않음.
- Expo 앱의 시스템 브라우저 로그인·deep-link 복귀. 현재 WebView에서 실제 OAuth 비활성화.
- 현재 위치 주변 검색과 서버 후보 조회 연결, 위치 동의 저장·철회, 원시 좌표 전송/파기와 이용 확인자료 보관 기준, 적용되는 신고·등록 확인.
- 운영자·문의 경로·수탁업체·처리 국가·로그 보존 기간·가입 연령 확정. 검수안은 국내 만14세 이상이며 대상 국가별 검토 필요.
- 실제 선택 메시지 발송·수신 거부와 Google/Apple 공식 브랜드 버튼의 출시 규격 적용.

약관은 실제 서비스 구성에 맞춰 검수할 초안. 사업자 정보·실제 처리 설계와 대상 국가를 반영한 출시 검토 완료본으로 표시하지 않음. 개인정보·위치 관련 확인 근거는 연결 계약 문서에 기록.
