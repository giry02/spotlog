# 관리자 업무 간소화 · 2026.10.12

사용자 요청: 관리 위치와 작업 순서를 찾기 어려움. 기존 기능 유지하면서 등록·검수·추천 여행·메인 게시 흐름을 쉽게 구성.

## 반영

| 작업 | 현재 화면 |
|---|---|
| 시작 | 운영 현황에서 지역 선택 → 장소 등록 / 검수하기 / 추천 여행 만들기. 자료 가져오기·지역 설정은 보조 행동 |
| 이어서 작업 | 선택 지역·담당 범위의 최근 미완료 자료로 직접 이동. 일반 운영자는 내 담당 기본, 최고관리자는 전체 담당 기본 |
| 지역 | 장소·업체 → 지역 설정에서 국가·시도·시군구 관리. 해당 지역 장소 목록으로 바로 이동. 설정 메뉴의 기존 진입점도 같은 화면으로 연결 |
| 장소 | 지역·종류별 목록, 내 담당·확인 필요·공개 빠른 필터. 상세 선택 시 목록 검색 접기. 장소명·종류·지역·주소·영업 상태·소개부터 입력 |
| 확인·공개 | 공개 전 확인 목록에서 위치·출처·사진·안내·AI의 해당 입력으로 이동. 초안 저장 / 검수하고 공개. 공개본 수정 중과 기존 공개본 구분 |
| 추가 관리 | 출처·사용 범위·운영 담당·추가 정보 접어서 제공. 기본 관리4탭, 안내·AI·이력은 추가 관리. 삭제·철회 등 기존 기능 보존 |
| 추천 여행 | 지역·기간·짧은 요청 → 초안 만들기 → DAY·방문 순서 다듬기 → 공개. DAY소개·장소 설명·사진 등은 추가 편집에서 제공 |
| 메인 | 공개한 추천 여행에서 메인에 게시 → 대상 자동 선택된 게시 편집기. 게시 기간·순서·활성 상태 명시 저장. 기존 게시가 있으면 같은 설정 편집 |

7개 왼쪽 메뉴 유지. 연결·검색 반영 오류·알림·수급·전체 지역 통계는 첫 화면의 전체 현황·연결 관리 안으로 이동. 미처리 신고는 바로 접근. 중복 영어 장식 제목 제거. 등록 화면 저장 버튼이 입력을 덮지 않도록 배치 조정.

## 자료·권한 보호

- 지역 원본은 기존 `state.regions`, `regionId`, `region.save`. `ops.references`의 옛 REGION 자료는 삭제·자동 병합하지 않으며 중복 지역 편집 화면에서 제외.
- 기존 공개·위치·출처·사진 사용권 검증 그대로 유지. 접힌 항목도 공개 전 검증 대상. 미완성 초안 저장 가능, 누락 항목 공개 불가.
- 공개와 홈 게시 분리. 새 메인 게시 편집기는 기본 비활성 초안이며 여는 것만으로 저장·노출하지 않음. HOME_TRIP 대상과 기존 기간·순서·표지 보존.
- 지역 변경은 새 추천 초안의 맥락으로만 사용. 기존 여행 내용을 바꾸지 않음. 이전 방식의 미완성 초안은 명시적인 이어서 작성으로 복구.
- 화면 이동 시 장소 입력·검색 상태 유지. 추천 여행과 지역 편집기는 서버 버전 변경으로 재생성하지 않아 충돌 시 입력 유지. 저장 중 추가한 입력도 승인된 revision과 함께 보존.
- API 모드 작성 내용은 브라우저 로컬 검수 캐시에 쓰지 않음. 실제 인증·권한 검사 및 연결 실패 화면 유지. 관리자 추가로 고객의 개인 여행·메모·예약·대화 원문 접근 경로 추가 없음.
