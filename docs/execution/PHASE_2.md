기준일: 2026-09-15 · 상태: 실행 지침 작성 완료 / 해당 차수 전체 구현 완료 아님

## 1. 구현 목표와 범위

내 여행에서 글·사진·장소를 편집·복구하고, 스팟 주변 음식점·숙소를 연결하며 여행기 속 카드별 소통을 구현함.

최초 일정: **2026-11-02~2026-12-28**, 40작업일(기능·검수 32일 + 수정 여유 8일). 일정은 추정이며 작업 완료 여부를 대신하지 않음. 엑셀에서 날짜/작업일을 조정했으면 변경된 일정과 아래 작업 ID를 대조함.

앞 차수의 완료 기록을 읽고 데이터 손실·잘못된 DAY·중복 반응 등 차단 결함이 없는지 확인한 뒤 시작함. 이전 차수의 검증 증거가 없으면 자동 완료로 간주하지 않음.

제품 전체 재작성·디자인 교체·새 보관함 계층·실제 서버/AI API 연결·공개 배포는 이 차수에 포함하지 않음. 현재 승인은 계획 및 인계 문서 제작임. 이 문서를 읽는 것만으로 구현·커밋·푸시가 승인되는 것은 아니며, 새 대화의 사용자가 해당 차수 구현을 요청하면 로컬 범위에서 실행함.

> Spotlog의 docs/execution/HANDOFF.md와 docs/execution/PHASE_2.md를 읽고 2차를 로컬에서 구현해줘. 먼저 최신 인수인계·진행 기록과 실제 활성 코드를 확인해 완료된 기능은 재사용하고, 아직 검증되지 않은 첫 작업부터 순서대로 진행해. 기존 화면 역할별 디자인과 사용자 데이터를 보존하고, 변경마다 완료 조건을 검수해. GitHub에 올리거나 커밋·푸시하지 말고, 중단 시 완료/진행/남은 작업 ID와 재현 방법을 인수인계에 기록해줘.
