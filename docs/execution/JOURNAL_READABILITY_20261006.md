# 여행기 동선·응원 글자 크기 보완 — 2026-10-06

사용자가 공개 사이트의 동선 지도·응원/댓글 화면에서 글자가 너무 작다고 지적. 해당 읽기 영역에 기존 역할별 글자 규격 적용.

| 영역 | 적용 |
|---|---|
| 지도 머리글·시간 메타 | 12px / 1.5 |
| 이동 장소·거리/시간·여유 시간·동선 요약 | 14px / 1.5 |
| 이동 검증 안내·지도 참고 설명 | 14px / 1.5 |
| 응원 선택 문구·빈 목록 안내·댓글 작성자·등급 안내 | 14px / 1.5 |
| 응원 수·댓글 수·작성 날짜 | 12px / 1.5 |
| 댓글 본문·입력 | 16px / 1.7, 입력400 |
| 댓글 등록 | 14px / 700, 높이44px |

9~11px로 남아 있던 의미 있는 한글 안내·행동 문구를 교정. 기존 타입 토큰 재사용. 평평한 밝은 배경의 보조 문구는 기존 승인 안내색 `#62625e` 사용.

동선의 긴 장소 이름은 숨기지 않고 줄바꿈. 지도 머리글과 반응 카드 높이는 내용에 맞게 확장. 응원 문구·빈 목록 설명·등급 안내는 단어 기준 줄바꿈. 작성자 줄은 필요할 때 다음 줄 사용하며 신고 아이콘 유지.

범위는 공개 여행기 동선·응원/댓글. 전체 폰트 토큰·DAY/표지·다른 화면의 버튼·실제 지도 처리·댓글 저장 계약 유지. 사용자 자료·관리자 소스 변경 없음.
