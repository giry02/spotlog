- 기존 사용자 저장 데이터를 덮어쓰지 않고 검수용 여행을 별도 주소에서 생성함.

검색어를 입력하면 기존처럼 지역 내 이름·주소 검색으로 전환하며, 거리 제한을 적용한 목록과 구분해 안내함. 3km/15km는 직선거리이며 도보 이동시간이나 실제 도로 거리를 뜻하지 않음. 기존 자동 일정 생성의 후보 계산은 변경하지 않음.

### 디자인 유지 기준

- 장소명16px, 보조 정보12px, 주변 업체 검색14px/400 유지
- 담기36px, 검색 지우기36px, 목록/범위 행동40px, 닫기44px
- 좁은 화면에서 글자를 줄이지 않음. 360px 이하 사진 없는 항목의 장식 영역 생략 규칙 유지
- 개인 일정의 커버·DAY 줄·카드 크기·사진 구조 유지
- 영어 인터페이스도 새 문구 적용. 실제 장소명·주소·출처 기관은 원문 유지
