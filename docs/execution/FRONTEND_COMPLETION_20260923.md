## 백엔드 개발자 연결 메모

아래는 프론트가 현재 받도록 만든 **연결 제안 규격**. 인증 제품/백엔드 API 최종 확정본이 아니며 상대 개발자와 맞춘 뒤 연결함. AI 규격 패키지 작업을 재개한 것은 아님.

### 설정

`web/.env.example` 참조. 로컬은 별도 `web/.env.local`에서 설정하고 개발 서버 재시작.

| 설정 | 예시/역할 |
|---|---|
| `VITE_NAVER_MAP_CLIENT_ID` | 네이버 브라우저 지도용 공개 ID. 비어 있으면 기존 MapLibre |
| `VITE_ROUTE_ENDPOINT` | `/api/routes/driving` — 우리 서버의 경로 조회 |
| `VITE_PLACE_SEARCH_ENDPOINT` | `/api/places/external` — 우리 서버의 외부 검색 |
| `VITE_ACCOUNT_ENDPOINT` | `/api/account` — 인증 경로의 공통 앞부분 |
| `VITE_TERMS_URL`, `VITE_PRIVACY_URL` | 실제 약관/개인정보 페이지 주소. 미설정 시 가입 요청 차단 |
| `SPOTLOG_DEV_API_TARGET` | 개발 중 `/api`를 받을 서버 주소. Vite 개발 서버에서만 사용 |

`VITE_*`는 브라우저에 공개됨. 네이버 REST 비밀 키·AI 키·DB 비밀번호 입력 금지. 운영에서는 같은 사이트의 `/api`를 실제 서버로 연결. 개발용 중계 설정을 운영 프록시로 간주하지 않음.

### 계정

- `GET /session`: `{id, displayName, email}` 또는 `null`/401
- `POST /sign-in`: `{email, password}` → `{id, displayName, email}`
- `POST /sign-up`: `{email, password, displayName, acceptedTerms:true}` → 성공 JSON 또는 204. 현재 UI는 메일 확인 후 로그인 안내를 사용하므로 실제 인증 방식 확정 시 맞춤
- `POST /password-reset`: `{email}` → 성공 JSON 또는 204. 가입 여부를 노출하지 않는 동일 안내
- `POST /sign-out`: `{}` → 성공 JSON 또는 204
- `POST /delete`: `{confirmed:true}` → 성공 JSON 또는 204
- 요청은 같은 출처 쿠키 방식. 서버에서 HttpOnly/Secure/SameSite, Origin/CSRF 검사, 권한, 재인증·요청 제한 구현 필요. 프론트의 확인 체크박스나 `X-Requested-With`만으로 보안을 충족했다고 보지 않음.
- 현재 기기의 여행·프로필은 기존 로컬 저장 방식 유지. 로그인 화면 추가가 회원별 데이터 분리·서버 동기화 완료를 의미하지 않음. 계정별 이관과 로그아웃 시 개인 자료 노출 정책은 서버 연결 때 함께 구현.

### 네이버 외부 검색

- `GET {endpoint}?query=...`
- 응답: `{provider:"NAVER", items:[{name,address,category,url}]}`
- 최대 5개, 원래 검색 순서 유지. 서버에서 제목의 표시 태그 정리, 출처 링크 확인, 해당 네이버 상품 이용 조건 준수.
- 프론트는 원문 보기만 제공. 외부 검색 결과를 내부 업체 ID/DB/RAG에 자동 등록하거나 AI 입력에 합치지 않음. 기존 허가 내부 후보와 사용자가 아는 업체 직접 등록은 별도 유지.

### 네이버 자동차 경로

- `POST {endpoint}`: `{mode:"DRIVE", visits:[{visitId,lat,lng}]}`
- 응답: `{provider:"NAVER", mode:"DRIVE", visitIds:[...], coordinates:[[lng,lat],...], legs:[{distanceMeters,durationSeconds}]}`
- 반환 `visitIds`는 요청 순서와 일치, 구간 수는 장소 수−1. 서버에서 네이버 단위를 위 단위로 변환해야 함.
- 네이버 지도 ID만 있고 경로 서버가 없으면 방문 순서의 직선만 표시. 실제 경로를 계산했다고 표시하지 않음.
- 네이버 설정이 전혀 없으면 기존 MapLibre/OSRM 참고 경로 유지. 이를 운영용 네이버 경로 연동 완료로 간주하지 않음.
