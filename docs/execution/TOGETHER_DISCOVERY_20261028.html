1홈에서 모임 홍보

AI 여행 만들기 다음에 공개 모집 영역 배치. 여행지·동네 선택, 지역 선택, 관심사, 사진 모집 카드, 다음 공개 일정 제공.

내 모임의 다음 여행은 별도 이어보기. 비공개 가족 모임은 공개 카드에 포함하지 않음.

2동네·관심사 탐색

🏡 동네에서 / 🧳 여행지에서 구분. 지역·동네 직접 선택. 맛집·카페·산책·여행·사진·레저·문화·가족 8개 관심사.

오늘·7일 안에·주말, 검색어, 일정순·이름순. 상세에서 돌아오면 조건·정렬 유지.

3가입 전 공개 소개

사진·활동 지역·관심사 → 첫 참여 안내 → 공개 일정·지난 활동 → 가입 조건 → 모임장 → 가입 신청.

비로그인도 열람 가능. 로그인 후 자동 가입하지 않음. 가입 신청과 일정 참가는 별도.

4모임장 모집 관리

모임 메뉴 → 공개 모집·홍보. 관심사·지역·모집 문구·가입 안내·대표 사진·공개할 일정 선택. 미리보기와 공개 범위 확인 후 게시.

모집 쉬기, 공개 소개 내리기 제공. 대표 사진 없이도 공개 가능.

5채팅 이모티콘

입력창의 웃는 얼굴 → 이모지 / 캐릭터. 이모지 60개, 토끼·고양이·곰·오리 4팩 34종.

캐릭터 선택 → 미리보기 → 보내기. 선택만으로 전송하지 않음. 텍스트와 함께 전송·재열기 가능.

6다양한 모임 예시

부산·서울·제주·강원·인천의 공개 모임 12개와 활동 24개. 카페 대화·한 끼 산책·사진·문화·가족 여행 등.

‘모임 예시’로 구분. 사진은 등록된 지역 자료 사용. 실제 개최·운영 실적을 뜻하지 않음.

확인한 동작

  • 부산·카페 선택 → 해당 모임만 표시 → 소개 → 뒤로 이동 시 조건·이름순 유지.
  • 비로그인 소개 열람 → 가입 클릭 시 로그인 방식 선택 → 로그인 후 같은 소개 복귀. 자동 신청 없음.
  • 가입 신청 → 승인 대기 → 신청 취소. 자동 가입·자동 일정 참가 없음.
  • 별도 화면 확인용 모임 생성 → 공개 범위 미확인 차단 → 명시적 공개 → 검색 반영 → 공개 소개 내리기 후 검색 제외.
  • 텍스트 초안에 이모지 삽입 → 캐릭터 선택 → 전송 전 미리보기 → 텍스트·그림 동시 저장 → 재열기.
