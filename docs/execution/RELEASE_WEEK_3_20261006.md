# 전체 일정 3주차 · 2026-10-06 보고분

업로드 준비일: 2026-09-29. 전체 일정 2주차 커밋 2ac1872 위에 2차 프론트 1주차를 선별 통합.

## 포함 기능
- 저장한 랜드마크로 비공개 개인 동선 생성. 기존 저장 화면의 날짜별 담기/바로 만들기 두 방식 유지.
- 내 여행 목록에서 개인 동선과 기존 여행기·이전 기록 구분. 기존 여행기 작성 진입 보존.
- DAY별 장소 목록, 저장한 랜드마크 추가, 방문 순서 조정과 자동 저장.
- 기준 랜드마크 주변 식당·카페 하단 팝업. 기존 예시 데이터의 좌표로 직선 15km 안 후보 정렬.
- 고른 업체를 기준 장소 다음에 담기. 기준 장소 순서 변경 시 연결한 업체도 함께 이동.
- 장소 제거 시 업체를 남길지 함께 제거할지 선택. 저장 목록에서 담김 해제해도 업체 연결이 끊긴 상태로 정상 유지.
- 개인 동선·주변 업체 보조 버튼 36px/12px. 기존 저장 상세보기와 모바일 스크롤 수정 유지.

## 통합 기준
- 2차 1주차 UI 보완 체크포인트 tree 4d48261e61d68c179025b3b4494ffff2d6b3aced의 해당 소스만 반영.
- 공개된 최신 저장 화면을 과거 체크포인트로 덮어쓰지 않고, 생성 결과를 개인 동선에 연결.
- 기존 여행기는 목적 정보를 강제 변환하지 않음. 새 개인 동선만 PLAN으로 저장.
- 이동 버튼은 연결된 업체를 제외한 장소 묶음의 처음/끝을 기준으로 비활성화.

## 검증
- 자동 검사 87개 통과, TypeScript/웹 빌드 성공.
- 390px: 협재해수욕장 저장 → 바로 만들기 → 주변 수우동 담기 → 새로고침 후 유지.
- DAY 2 빈 상태 → 저장 랜드마크 담기 → DAY 1과 독립된 방문 유지.
- 날짜별 담기에서 DAY 2에 배치 → 생성 후 DAY 1은 비고 DAY 2에 해당 장소 유지.

- 검수 탭 콘솔 오류·경고 없음. 자동 검사는 장소/업체 연결 이동·제거·중복 방지·좌표 누락을 포함.
