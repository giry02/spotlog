여행 동선이 없어도 시작하는 동네·취미 모임

기존 개인 여행·여행기·가족 여행 유지. 함께하기는 일반 모임과 번개·정모를 기본으로 구성.

모임 찾기가입·승인 직접 확인홈 모임 홍보

가입 신청부터 모임장 승인까지 직접 확인

전용 화면에서 실제 고객 화면을 재사용. 신청자와 모임장은 같은 검수 자료를 보며, 실제 로그인 계정이나 고객·관리자 저장소는 변경하지 않음.

  1. 신청자 수아목록의 ‘동네 한 잔과 취미 친구’ 선택 → 소개 확인 → ‘이 모임 가입 신청’.
  2. 가입 인사 보내기인사 입력 → 모임 안내 확인 → ‘가입 신청 보내기’. 승인 대기로 바뀌며 아직 내부 채팅·게시판에 들어갈 수 없음.
  3. 모임장 지민으로 전환상단 역할 버튼 선택 → 모임 홈의 ‘새 가입 신청 1건’.
  4. 가입 신청 검토수아 선택 → 인사·신청 시각·승인 범위 확인 → ‘가입 승인’. 처리 완료 목록에 남음.
  5. 가입한 수아로 전환모임 홈·전체 채팅·게시판·앨범 접근 가능. 모임원은 2명에서 3명으로 변경.
  6. 정모 참석은 별도 선택‘정모 참석 확인’ → 날짜·19:30·장소 확인. 처음에는 참석 2/6명, 수아가 ‘참석’을 눌렀을 때 3/6명.

‘검수 처음부터’를 펼쳐 확인한 뒤 이 탭의 검수 기록만 초기화 가능. 별도 브라우저·기기로 전달되는 실제 가입과 승인은 서버 연결 단계.

모임 / 번개·정모

동네와 여행지로 나누던 첫 화면을 변경. 지역·동네, 관심사 선택 후 모임 목록을 바로 표시. 날짜와 검색은 필요할 때 펼침.

관심사 16개

이웃·친목, 맛집, 카페, 산책, 운동, 독서, 문화, 보드게임을 먼저 표시. 사진·레저·음악·언어·공예·반려동물·가족·여행은 더보기.

일반 정모 등록

함께할 내용 → 날짜·시작 시간 → 만날 장소 → 준비 내용. 정원은 선택. 여행·여러 날 일정 연결은 접힌 선택 항목.

정모 안내

언제·어디서·누가 참석하는지가 먼저 보임. 동선이 없어도 미완성 오류처럼 보이지 않음. 일반 정모의 장소 선택은 모임 장소만 변경.

모임장 가입 관리

새 신청 건수를 모임 홈에 표시. 대기/처리 완료 목록 분리. 신청 인사와 시각을 읽고 승인·거절. 결정 시각·운영자 기록.

모임 예시 20개

공개 활동 40개. 독서·보드게임·배드민턴·러닝·공예·음악·언어·반려동물 모임 추가. 관련 없는 바다 사진을 취미 모임 사진으로 사용하지 않음.
