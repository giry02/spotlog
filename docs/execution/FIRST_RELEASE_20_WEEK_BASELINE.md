# Spotlog 기준 일정 — 사용자 선택 20주안

저장일: 2026-09-15 · 상태: 사용자가 아래 표를 기준 일정으로 선택

**조회 규칙:** 사용자가 이 프로젝트에서 “일정”, “일정 보여줘”라고 요청하면 아래 6행 표를 그대로 보여준다. 별도 변경 요청 전에는 날짜·기간·기능을 바꾸거나 휴일 보충안·이전 24주안으로 대체하지 않는다. 기획·설계·구현·고객 확인·수정 항목을 일정표에 추가하지 않는다.

**프론트 6주 → 백엔드 5주 → AI/RAG 5주 → 앱 연결·출시 4주. 첫 오픈 목표 2027-02-02(화).**

AI/RAG 기간은 기존 5주를 유지한다. 직무별 담당은 각 1명이며 프론트 완료 → 백엔드 완료 → AI/RAG 완료 순서로 진행하고 마지막 앱 연결·출시에 함께 참여한다.

| 단계 | 주요 기능 | 기간 | 일정 |
|---|---|---:|---|
| **1차 프론트** | 발견·저장·사진 갤러리·여행/DAY 담기 | **2주** | 2026.09.15~09.29 |
| **2차 프론트** | 편집·복구·주변 업체·지도·댓글 | **2주** | 2026.09.30~10.13 |
| **3차 프론트** | 기본 AI 추천 화면·계정·앱 화면 | **2주** | 2026.10.14~10.27 |
| **백엔드** | 계정·저장·사진·댓글·업체 ID·순위·좌표·네이버 연결 | **5주** | 2026.10.28~12.01 |
| **AI·RAG** | AI 서버·검색·업체 연결·기본 추천·결과 저장 | **5주 유지** | 2026.12.02~2027.01.05 |
| **앱 연결·출시** | 실제 서버·AI 연결·Android/iOS·스토어 공개 | **4주** | 2027.01.06~02.02 |

위 기간은 달력 주수 기준이며 공휴일을 보충해 종료일을 늘린 일정은 아니다. 09/15는 착수일로 별도 두고 09/16부터 평일을 계산하면 휴일 제외 가용일은 94일이다. 상세 검토는 [20주안 휴일 비교](HOLIDAY_REVIEW_20_WEEK.md)에 분리해 기록한다. 비교안은 이 보관본을 자동 대체하지 않는다.

첫 오픈은 기존 화면·앱 구조 재사용, 관리형 서버·외부 모델 API, 제한 지역의 초기 장소/업체 약 100건과 제공된 내부 순위 자료를 전제로 한다. AI는 기본 당일 추천·승인 후 여행 저장까지 포함한다. 복잡한 다일 최적화·부분 재생성·관광 대화·영어 확장은 후속이다. 프론트 기간의 AI·서버 응답은 예시이며 실제 화면 연결은 마지막 단계에 진행한다. 업체 ID·순위·주소·좌표는 백엔드에서 연결하고 AI/RAG가 같은 ID의 자료를 사용한다.

목표일은 실제 작업량·외부 자료·앱 승인에 따라 조정할 일정안이다. 휴일 비교와 별도로 휴가·새 요구·기존 코드 상태·스토어 심사 기간을 확인해야 한다.
