## 사용 흐름

저장 화면의 각 장소 카드에서 작은 `상세보기 >` 버튼을 누르면 하단 팝업이 열린다.

- 사진, 같은 장소의 여러 사진 넘김, 사진별 설명과 출처.
- 장소 소개, 메모, 태그, 주소, 등록된 추천 체류시간과 방문 참고 정보.
- 사진 출처를 열면 같은 팝업 안에서 전환하고 뒤로 돌아오면 선택한 사진을 유지한다.
- 닫기·바깥 클릭·뒤로가기로 저장 목록에 복귀한다. 저장 상태와 여행/DAY 담김은 바꾸지 않는다.
- 상세보기 버튼은 기존 담기 버튼 옆에12px 글자·34px 높이로 배치한다. 좁은 화면에서는 줄을 바꾸며 글자를 더 줄이지 않는다.

현재 등록된 장소 데이터를 보여주는 기능이다. 외부 API 조회나 새로운 장소 데이터 수급을 구현한 것은 아니다.
