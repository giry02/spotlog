# 3차 로컬 구현 — 여행 중 안내·영어·원문 보존

2026-09-19 · 대상: P3-07 / P3-08 / P3-09 · 공개 반영 없음

## 변경한 기능

- 내 여행에서 현재 여행과 DAY를 전달받아 관광 안내 하단 팝업을 연다. DAY와 현재 방문 장소를 바꾸어 오늘 순서·다음 장소·등록된 소개를 확인하고 질문할 수 있다. 같은 장소를 여러 번 방문해도 방문 ID로 구분한다.
- ‘운영 정보’, 접근성, 알레르기, 긴급 상황 등 등록 자료로 확인할 수 없는 질문은 확인 불가와 직접 확인 방법을 안내한다. 실시간 영업·가격·대기시간·경로·후기를 생성하지 않는다. 출처는 내 여행의 등록 정보이고, 확인일이 없으면 ‘자료 확인일 미등록’으로 표시한다.
- 한국어/English 전환을 공통 리소스로 관리한다. 언어는 별도 환경설정만 바꾸며 여행·장소·DAY·원문을 수정하지 않는다. 안내 팝업 안에서 언어를 바꾸어도 DAY와 방문 선택은 유지한다.
- 저장에서 ‘날짜별로 담기 / 바로 만들기’, 기간 선택·DAY별 담기·순서 변경·기간 단축 시 미배치 안내·오류·내 여행 생성 팝업을 영어 리소스로 연결했다. 장소명과 주소는 한국어 원문을 유지한다. 입력 구조와 선택 값은 바꾸지 않는다.
- 한글 장소명·주소 크게 보기 및 복사를 제공한다. 기존 하단 팝업 내부 상세 보기로 열어 뒤로 가면 질문과 DAY 선택으로 돌아온다. 복사가 거절되면 성공했다고 표시하지 않고 수동 복사 방법을 안내한다.
- 여행기 본문·사진 설명·댓글에 요청형 영어 보기 컴포넌트를 연결할 수 있다. 등록한 샘플 문장만 ‘번역 예시’로 제공한다. 임의 사용자 글은 번역 서비스를 연결하기 전까지 원문과 번역 미제공 상태를 유지한다. 임의 글을 번역한 것처럼 표시하지 않는다.
- 번역 재사용은 원문 ID·버전·전체 원문·언어·용어집 버전이 모두 같을 때만 허용한다. 원문 또는 용어집이 바뀌면 오래된 번역을 숨기고 다시 번역이 필요하다고 표시한다. 향후 검수된 응답을 받으면 ‘검수 완료’를 별도로 표시할 수 있지만 현재 샘플을 검수 완료라고 표시하지 않는다.
- 안내·번역 요청은 취소와 늦은 응답을 구분하고 팝업 닫기/대상 변경 이후 응답으로 다른 DAY나 원문을 덮어쓰지 않는다.
- 어댑터 응답은 화면·번역 캐시에 넣기 전에 요청/버전, 본문 문자열, 번역 상태, 출처 목록·확인일, 경고·미배치 목록을 실제 값으로 검사한다. 요청 ID가 맞더라도 잘못된 JSON 구조이면 기존 오류 안내를 표시하고 원문과 여행은 유지한다.

## 파일·연결 계약

- `web/src/TravelGuideSheet.tsx`: `default TravelGuideSheet({journey, initialDay, onClose, adapter?})`. Journey.days가 비어 있어도 빈 상태를 제공한다.
- `web/src/locale.tsx`: `LocaleProvider`, `useLocale`, `LanguageControls`, `uiMessages`, `message`. 루트에서 Provider를 한 번 감싸고 필요한 기존 화면의 레이블만 리소스로 연결한다. 기존 본문을 DOM에서 강제로 치환하지 않는다.
- `web/src/SavedTripControls.tsx` / `CreatePlanSheet.tsx`: 공통 `tripMessage` 리소스로 기존 여행 생성 흐름의 레이블·안내·오류를 전환한다. 출발일 입력은 기존 브라우저 호환 규칙대로 `onInput`과 `onChange`를 함께 받는다.
- `web/src/TranslationText.tsx`: `TranslationText({sourceId,sourceVersion,text,kind,showOriginal?,glossaryVersion?,adapter?})`. 기존 디자인의 본문을 유지하며 버튼을 추가할 때 `showOriginal={false}`를 쓴다.
- `web/src/travelGuide.ts`: 독립 `localGuideAdapter` / `localTranslationAdapter` 및 순수 함수. `aiPlanner.ts`의 요청·응답 계약을 공유한다.
- `web/src/travel-guide.css`: 기존 폰트 토큰과 36px 보조 버튼·16px 입력·12px 보조 정보 역할만 사용한다. 전역 CSS·폰트·기존 카드 역할은 변경하지 않는다.

## 실제 서비스 연결 시 남는 작업

관광 안내/RAG/번역 서버 어댑터, 데이터 권한·최신 확인일·운영 정보 공급, 전문 번역 검수와 용어집 운영, 로그인 사용자별 권한/캐시 범위는 서버 단계에서 연결한다. 현재 로컬 인터페이스 및 샘플의 성공을 실제 AI·번역·인증 완료라고 보고하지 않는다. 기존 레거시 화면의 모든 문구가 영어로 바뀐 것은 아니며, 안내 흐름과 연결한 메뉴/환경설정 범위가 우선 적용 대상이다.
