# 고객 프론트 GitHub 반영 · 2026.10.08

사용자 요청: ‘깃에올려’. 이전 관리자 제외 조건 유지. 최신 고객 검수본만 기존 공개 브랜치 `codex/mobile-foundation`에 반영하고 기존 Pages 자동 배포 사용. 원래 고객·관리자 통합 로컬 작업본과 별도 작업본의 미완료 변경은 그대로 보존.

## 포함한 변경

- 일반 이메일 로그인·회원가입, 약관 동의 후 같은 정보 화면에서 이메일 인증, 개인정보·위치 이용 안내. 비로그인과 실제 회원·기기 기록 구분.
- Google/Apple 버튼은 실제 제공자 인증 결과를 받기 전 가입 화면으로 이동하지 않음. 미연결·취소·실패 시 이메일 입력과 로그인 화면 유지.
- 로컬 DEV 검수 계정 입력과 한 번 로그인. 실제 인증 서버 설정 시 실제 어댑터 우선. 운영 번들에는 검수 이메일·비밀번호·회원 ID가 포함되지 않음.
- 숫자 오류 코드를 고객에게 표시하지 않는 오류 안내, 독립 `error.html`, 정적 호스트 `404.html`, 앱 주소·렌더 오류 복귀 처리.
- 내 여행과 여행기 구분, 주변 업체 여러 후보 담기와 최종 선택, 준비 초안 보존, 지역별 검수 업체 자료.
- 고객용 공용 데이터 계약·테스트와 계정 연결 계약. 기존 신고·댓글·답글·길찾기·한국어 화면 유지.

## 제외 및 연결 전 항목

- 관리자 진입점·소스·스타일·테스트·검수 이미지 및 관리자 계약 제외.
- 실제 회원 인증·메일 발송·Google/Apple 인증·GPS 서비스·DB·AI·신고 접수는 서버 연결 전. 공개 사이트의 로그인 성공이나 발송 완료를 가짜로 표시하지 않음.
- 약관·개인정보 문서는 운영자·주소·문의 이메일 미정인 초안. 실제 가입 활성화 전에 서버의 확정 정책 버전 필요.
- 고객 저장 자료를 초기화하거나 관리자 자료와 합치지 않음.

## 검수

- 독립 작업본에서 `npm ci`와 TypeScript 포함 고객 빌드 성공. 관리자 HTML/JS/CSS와 로컬 검수 계정 문자열 제외 확인.
- 계정·오류·여행 생성 초안·업체 후보·일정 보호·공용 자료·신고 문맥 관련 자동 검사 70개 통과.
- 최신 로컬 로그인 26상태, 이메일 가입 24상태, 오류 화면 45상태 검수 결과 유지.
- 배포 형식 정적 서버에서 오류 페이지 10상태 통과. 실제 HTTP404, 중첩 주소의 홈 복귀, 개발 목록 제외, 스크립트·에셋 오류 없음.

업로드 커밋·배포 작업과 공개 사이트 최종 확인 결과는 로컬 현재 인수인계에 기록. 기존 MapLibre 번들 크기 경고는 유지하며 빌드 오류는 없음.
