## 확인한 사용자 동작

- 독립 검수 주소의 실제 브라우저에서 DAY 1 두 번째 장소 선택 → DAY 2 → DAY 1 → 닫기 → 재열기를 진행했다. 방문 선택·질문·답변이 유지됐다.
- ‘오늘 일정’ 요청 실패 → 입력을 ‘다음 장소’로 수정 → ‘다시 시도’를 진행했다. 요청 기록이 `오늘 일정 → 오늘 일정`으로 표시되고 응답 제목도 실제 질문과 일치했다.
- 원문 병행 표시에서 영어 보기 후 ‘번역 접기’ 레이블과 펼침 상태를 확인했다.
- 프로필 이름 누락 시 포커스 복귀, 한국어 오류의 영어 전환, 저장 예외 후 기존 프로필 유지와 오류 표시를 확인했다.
- 안내/응답과 프로필의 320px, 안내 영어의 390/460px 팝업을 브라우저에서 확인했다. 확인한 화면의 입력·버튼·본문은 잘리지 않았다. 기존 글꼴 척도와 화면 외형은 변경하지 않았다.

검수용 파일: `web/tests/guide-review.html`, `guide-review.tsx`. 사용자 저장 데이터를 수정하지 않는 메모리 샘플이며 제품 메뉴에는 연결하지 않는다. 별도 localhost 검수 탭은 종료했고 언어를 한국어로 복원했다.

## 자동 검사와 한계

이번 안내 복원은 팝업 닫기와 다시 열기의 세션 범위다. 새로고침·앱 재시작 후 복원이라고 표시하지 않는다. 이는 AI 작성 초안의 별도 복구 작업과 구분한다. 실제 Android/iOS 기기, 외부 AI·번역 서버는 이번 검수 대상이 아니다.
