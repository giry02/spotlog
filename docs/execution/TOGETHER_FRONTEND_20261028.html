검수 순서

  1. 함께하기에서 로그인. 기존 로컬 검수 계정의 이메일 로그인 사용. 실제 서비스 계정에 예시 회원이나 모임을 자동 배정하지 않음.
  2. 우리 가족 여행 → 부산 가족여행 → 음식점·숙소 펼치기. 사진·주소·소개·출처·네이버 길찾기 확인.
  3. 준비 → 담당 할 일 완료 체크 → 새로고침 후 유지 확인. 참가·미정·불참은 열람 권한과 분리.
  4. 이 일정 채팅 → 대화 정리 → 범위·사람 선택 → 정리 예시 보기. 원문 이동, 준비 항목 선택 적용, 공지·투표 초안 확인.
  5. 받은 초대 → 수락. 첫 수락 시 한 모임 생성, 초대자 모임장, 자동 참가 처리 없음.
  6. 개인 여행의 더보기 → 함께하기. 완성한 일정은 공동 일정으로 독립 복사. 미선택 후보·개인 메모·요청문은 공유에서 제외.
  7. 관심 장소 → 새 목록 → 장소 담기. 여러 목록에 같은 장소 저장, 목록 삭제 시 기존 찜·여행 유지. 지도는 장소 핀만 표시.
  8. 모임·일정·채팅 진입 후 상단 뒤로와 브라우저 뒤로를 조합해 복귀. 상세에서 하단 메뉴 중복 표시 없음.
