# 관리자 UI 간격·정렬 보완 · 2026-10-05

사용자가 지적한 ‘채널별 노출’의 붙어 있는 선택·검색·빈 결과 영역을 관리자 공통 컴포넌트에서 수정. 장소·추천·커뮤니티·회원·AI·설정에도 같은 간격 적용. 로컬 검수본만 반영.

## 수정 내용

| 영역 | 변경 |
|---|---|
| 공통 카드 | 제목/행동 영역과 본문 분리. 본문 항목 간 20px, 작은 화면 18px. 카드 안쪽 여백 24px부터 화면 폭에 따라 16px까지 조정 |
| 검색·입력 | 라벨→입력 8px. 검색창과 초기화 버튼은 42px 높이로 나란히 정렬. 검색→결과 사이 여백 확보 |
| 목록·버튼 | 버튼형 카드/목록에 일반 버튼 규칙이 덮어쓰던 padding·gap·정렬 수정. 링크형 보조 버튼에도 같은 버튼 외형 적용 |
| 사진 편집 | 96×80px 썸네일, 작은 화면 72×64px. 파일 정보 / 출처·사용 조건 / 사용 범위로 입력 구획 분리. 기존 출처·권한·사진 순서·철회 동작 유지 |
| 좁은 화면 | 1100px 이하 메뉴 접기로 편집 영역 확보. 800px 이하 목록·상세 전환 유지. 상단 작업자·역할·조회는 작은 화면에서 별도 행, 360px 이하 역할 이름 잘림 방지 |
| 기타 편집 | 연결 한도 입력+저장을 한 그룹으로 정렬. 여행기 장소 사진/본문 정렬 및 사진 없는 DAY 장소 본문 위치 보완. 카드 설명·원문이 완전히 같으면 화면에서 한 번만 표시(저장된 원문 유지) |

고객 화면 CSS·사진 피드·버튼·폰트·사용자 저장소는 이번 작업의 수정 대상에서 제외. 등록/공개/신고/권한/미연결 안내/데이터 계약 변경 없음. 실제 서버·AI·사진 업로드 연결 전 상태 유지.
