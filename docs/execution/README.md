# Spotlog 개발 실행 문서

2026-09-15 기준. 기존 계획서를 차수별 실제 작업과 검수 기준으로 나눔. 서비스 기능을 새로 구현한 결과 보고서가 아님.

## 최신 협업 일정안

**사용자 선택 기준:** 사용자가 “일정”이라고 하면 [기준 일정의 6행 표](FIRST_RELEASE_20_WEEK_BASELINE.md)를 그대로 보여줌. 2026-09-15~2027-02-02의 20주안이며 별도 변경 요청 전에는 휴일 비교안이나 과거 일정으로 대체하지 않음.

[현재 20주 보관안](FIRST_RELEASE_20_WEEK_BASELINE.md)을 사용자 요청대로 유지함. 프론트 1·2·3차 각 2주(총 6주) → 백엔드 5주 → AI/RAG 5주 유지 → 앱 연결·출시 4주, 2027-02-02 첫 오픈 목표임. [휴일 비교 검토](HOLIDAY_REVIEW_20_WEEK.md)는 별도 참고이며 보관안을 자동 대체하지 않음. 현재 날짜의 휴일 제외 가용일은 94일이고, 단계별 주수×5평일을 확보하는 비교안은 02/12 종료·02/16 화요일 보고임. 기존 [24주 기능별 일정](FIRST_RELEASE_24_WEEK_PLAN.md)은 이전 대안으로 보존함. 일정표는 기능 중심 형식을 유지하며 날짜는 협의 목표임.

아래 최초 차수별 날짜와 기존 Excel, [이전 화요일 보고안](TUESDAY_CLIENT_REVIEW_SCHEDULE.md), [이전 병행 일정](COLLABORATIVE_DELIVERY_PLAN.md), [43주 순차안](SEQUENTIAL_DELIVERY_PLAN.md)은 이전 산정임. 기존 기능 지침은 보존하고 현재 목표는 20주 보관안, 휴일 보충 계산은 별도 비교 문서에서 확인함.
