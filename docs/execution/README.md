# Spotlog 개발 실행 문서

2026-09-15 기준. 기존 계획서를 차수별 실제 작업과 검수 기준으로 나눔. 서비스 기능을 새로 구현한 결과 보고서가 아님.

후속 사용자 승인으로 수행한 **1차 로컬 기능 구현·웹 검수 결과는 [진행 기록](PROGRESS.md)**에서 확인함. 이번 주 1차 작업분은 `a123166`으로 [GitHub 백업](PHASE_1_WEEK_1_CHECKPOINT.md)을 완료했고 활성화하지 않음. 실제 Android 검수와 전체 카탈로그 수급·서비스 공개는 별도임.

**최신 2차 구현 계획:** [저장한 랜드마크로 쉽게 만드는 내 여행](PHASE_2_IMPLEMENTATION_PLAN.md). 사용자의 최신 구분에 따라 개인 동선은 저장 → DAY 뼈대 → 랜드마크 주변 업체 하단 모달 → 선택/검색/등록 → 지도 흐름으로 먼저 구현함. 여행기 글·사진 작성과 카드 소통은 타인에게 보여주는 별도 선택 흐름으로 둠. 아래 최초 날짜는 이전 이력이며 2차 프론트 목표 09/30~10/13은 유지함. 계획 문서만 수정했고 제품 코드는 변경하지 않음.

**서비스 기능 검토:** [휴지통·삭제 복구 사용자 기획안](TRASH_USER_FLOW.md). JSON 파일 백업·복구 메뉴는 사용자 지시로 제외했으며 휴지통은 화면 구현 전 사용 흐름을 검토하는 단계임.

## 최신 협업 일정안

**사용자 선택 기준:** 사용자가 “일정”이라고 하면 [최신 기준 일정의 6행 표](FIRST_RELEASE_20_WEEK_BASELINE.md)를 보여준다. 2026-09-18 변경 기준은 프론트 일정 고정, 백엔드 5주, AI/RAG 4주로 12/29 개발 완료, 2027년 1월 한 달 테스트·여행 데이터 수집이다.

[최신 기준 일정](FIRST_RELEASE_20_WEEK_BASELINE.md)은 12/30~12/31 인수인계 후 01/01~01/31 테스트·여행 데이터 수집, 02/02 화요일 최종 보고로 이어진다. 서버/AI/앱 연결 검증과 스토어 제출 준비를 1월에 포함하며 실제 공개일은 테스트와 승인 결과에 따른다. [휴일 비교](HOLIDAY_REVIEW_20_WEEK.md)와 [24주 일정](FIRST_RELEASE_24_WEEK_PLAN.md)은 이전 산정이다.

아래 최초 차수별 날짜와 기존 Excel, [이전 화요일 보고안](TUESDAY_CLIENT_REVIEW_SCHEDULE.md), [이전 병행 일정](COLLABORATIVE_DELIVERY_PLAN.md), [43주 순차안](SEQUENTIAL_DELIVERY_PLAN.md)은 이전 산정이다. 기존 기능 지침은 보존하고 날짜는 위 최신 기준 일정에서 확인한다.
