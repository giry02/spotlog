# 입력·팝업 글자 비교 검토

검토일: 2026-09-15. 사용자 요청 범위는 입력창과 팝업의 글자가 일반적인 서비스보다 큰지 확인하는 것이다. 기존 외형과 제품 코드는 이 검토에서 변경하지 않았다.

## 측정 조건

여기어때, NOL 공식 웹사이트와 Spotlog 로컬 화면을 동일한 390px 너비의 브라우저에서 열어 최종 적용된 CSS 값을 읽었다. 네이티브 앱 측정이나 각 회사의 공식 디자인 시스템 전체 규격은 아니다. 검색창과 여행 작성 폼은 용도가 다르므로 직접적인 복제 기준으로 쓰지 않는다.

## 실제 측정값

| 서비스·위치 | 크기 | 굵기 | 비고 |
|---|---:|---:|---|
| [여기어때](https://www.yeogi.com/) 홈 검색 진입 문구 | 15px | 500 | 입력창을 여는 버튼 안의 실제 문구. 부모 버튼의 16px과 구별 |
| 여기어때 검색 팝업 입력·빈칸 안내 문구 | 16px | 500 | 실제 텍스트 입력 요소, 줄높이19px |
| 여기어때 인원 팝업 ‘인원’ 제목 | 18px | 700 | 안내12px/400, 인원 숫자16px/700 |
| [NOL 검색 화면](https://nol.yanolja.com/discovery/s/search) 입력값 | 16px | 700 | 빈칸 안내 문구는16px/400. 줄높이19px |
| Spotlog AI 여행·새 여행 입력값 | 16px | 400 | 입력·선택·빈칸 안내의 크기와 굵기 일치 |
| Spotlog AI 여행·새 여행 팝업 제목 | 20px | 700 | 줄높이28px |
| Spotlog AI 여행 항목명 | 14px | 600 | 보조 설명13px/400 |
| Spotlog 새 여행 항목명 | 12px | 700 | 기존 화면의 예외. 하단 설명도12px/400 |

## 판단

- **16px 입력 자체를 과도하게 크다고 판단할 근거는 없다.** 비교한 두 서비스의 실제 검색 입력과 크기가 같다. 다만16px은 모든 서비스에 적용되는 의무 규격이 아니라 Spotlog가 채택한 입력 역할값이다.
- **팝업 전체를 같은 기준으로 묶으면 안 된다.** Spotlog 제목20px은 확인한 여기어때 인원 제목18px보다2px 크지만, 서로 다른 목적의 팝업이다. 한 사례만으로20px이 잘못된 크기라고 판단하지 않는다.
- 새 여행 화면에서는 항목명12px 옆에 입력16px이 놓여 크기 차이가 두드러진다. AI 폼의 항목명은14px이므로 두 폼의 크기 대비도 다르다. 이는 입력이 갑자기 커 보이는 데 영향을 줄 수 있다.
- Spotlog 여행 제목 입력과 AI 문장 입력의 줄높이는27.2px이다. 비교한 검색 입력은19px이다. 글자 크기는 같지만 줄 간격과 여백이 더 넉넉한 인상을 만든다. 특히 여러 줄 입력의 줄높이는 단일 검색창과 용도가 다르다.
- 이전 AI 입력의600 굵기 상속 문제는 앞선 작업에서400으로 수정되어 있다. 이번 측정에서도400을 확인했다. 크기16px을 줄인 수정은 아니다.
- 서체 선언도 다르다. 비교 사이트들은Pretendard를 우선 선언하며 Spotlog는DM Sans 다음에Pretendard를 선언한다. Spotlog는Pretendard를 별도로 공급하지 않아 한글이 대체 서체로 표시될 수 있다. CSS의font-family 선언만으로 실제 한글에 사용된 글꼴을 확정하지 않는다.

현 단계에서는 입력16px/400을 유지할 수 있다. 제목·카드·항목명·간격·서체를 이번 비교만으로 변경하지 않는다. 더 작은 입력이 필요한지 결정할 때에는 입력 역할만 별도로 비교하고 기존 외형에 확대 적용하지 않는다.
