## 앱에 반영

| 기능 | 사용 흐름 | 보존 기준 |
|---|---|---|
| 홈에서 내 여행 이어가기 | 기기에 저장한 개인 여행이 있으면 홈에 한 장 표시. 한 번 누르면 마지막 DAY와 다음 미방문 장소 열기. 현재 DAY가 끝났으면 다음 미방문 DAY로 이동 | 공개 여행기·휴지통 제외. 모든 방문 확인이 끝나면 ‘내 여행 보기’. 후보 확인 중인 여행은 자동 완성하지 않음 |
| 후보 비교 정보 | 기존 ‘마지막 확인’에 사진64px, 기준 랜드마크 직선거리, 등록된 특징 최대3개·소개 표시. 카드 탭으로 한 곳 선택 | 이동 시간으로 오인하지 않도록 거리 기준 표시. 미등록·실패 사진 대체, 철회 사진/명시적 빈 갤러리 제외. 출처 팝업 재사용, 예약 고정·후보 선택 복원 유지 |
| 다녀온 곳으로 여행기 초안 | 방문 완료한 곳이 있으면 기존 여행기 버튼 한 번으로 완료 장소만 별도 비공개 초안 생성. 기존 ‘내 여행 관리’에서 ‘예정 장소도 포함’ 선택 가능 | 건너뛴 방문 제외. 완료한 곳이 없으면 기존 예정 장소 초안 흐름 유지. 전부 건너뛴 경우 빈 여행기 생성 차단 |

최근 여행 ID를 기존 검증·백업 저장소에 포함. 서로 다른 여행 중 마지막으로 열었던 개인 여행을 이어가며, 공개 여행기 탐색이 이를 바꾸지 않음. 같은 업체라도 `visitId`가 다른 방문은 구분. 새로고침·로그인/로그아웃에도 기기 기록 보존. 회원 계정으로 자동 병합하지 않음.

여행기에는 원래 DAY·날짜·전체 여행 기간 유지. 완료한 방문이 마지막 DAY에만 있으면 첫 내용이 있는 DAY부터 작성 화면을 열고, 사용자가 따로 고른 DAY는 다시 접속해도 최우선 복원. 개인 메모·예약 고정·계획 시각·이동 예측·진행 기록·계획 조건은 여행기 내용으로 옮기지 않음. 장소 사진의 출처는 유지하고, 원본 여행과 독립 ID로 저장.

최초 AI 입력·필수 확인 단계 추가 없음. 기존 모바일 셸·메뉴·DAY·BottomSheet 재사용. 입력/장소 이름16px, 행동/소개14px, 보조 정보12px. 새 체크 항목과 후보 삭제·출처 행동44px, 긴 이름 줄바꿈 및320px 화면 확인.
