지역 판정은 현재 저장 목록과 같은 `area`의 시·도 앞부분 기준. 서울·제주 같은 떨어진 지역을 무심코 합치는 문제를 막는 조치. 같은 도 안의 장거리 이동이나 실제 이동 가능성을 보장하는 경로 계산은 아님. 백엔드 연결 때 지역 ID와 좌표·이동 시간으로 추가 검증 필요.

지역 선택을 닫았다 다시 열면 현재 저장 범위에 유효한 선택을 유지. 다른 지역의10곳을 숨기거나 삭제하지 않고 저장 목록에 보존. 자동 생성 함수에서도 혼합 지역을 거부해 화면을 우회해 호출해도 임의로 합치지 않음.

AI 최초 입력은 요청 문장·예시·지역/기간/속도/이동수단4개 조건 그대로. 날짜·동행·숙박 등 입력 항목을 다시 추가하지 않음. 요청에 맞는 식사·카페·숙박을 포함한 완성 샘플 결과와 결과 수정 흐름 유지.

## 글자와 버튼 기준

- 본문·일반 입력16px/400, 장소명16px, 기존 제목·글꼴 가족 유지.
- 핵심 보조 행동·종류·실제 수량12px. 안내는14px, 홈 작은 카드 소개는 기존13px 예외.
- 사진 출처11px, 저장 카드 지역/DAY 메타11px와 작은 영문 장식 예외는 유지. 화면 전체의 글자를 일괄 확대하지 않음.
- 저장 카드 담기: 실측 약36.39px 높이·12px 글씨. 개인 일정 도구: 실측 약38.39px·12px, 같은 줄 동일 높이. 다음 완료:36px 보조 역할.
- 좁은 화면에서 폰트를 줄이지 않음. 저장 만들기 제목은 필요하면 줄바꿈. 긴 개인 여행 이름은 상단 헤더 한 줄 말줄임, 아래 표지를 늘려 전체 표시.

반영 규칙은 [스타일 가이드](../STYLE_GUIDE.md) 최신10/02 항목과 버튼 표에 갱신.
