## 자료 보호와 연결 경계

- 83개 원본은 좌표·사용권을 임의 승인하지 않은 초안. 가져왔다는 이유로 공용 추천·AI 허용 안 함. 비공개 홈 수정 초안은 미검수 자료를 확인할 수 있으나 공개 검증은 동일하게 적용.
- 기존 관리자 자료는 idempotent migration으로 보완. 편집·공개본·삭제한 미디어·조치 보존. 이전 편집 캐시는 revision 충돌로 차단하고 입력 유지.
- 고객 개인 일정·예약·메모·AI 입력·대화 원문은 기본 관리자 수집/열람 제외. 명시적인 공개 신고·반응 문맥만 개발 검수 저장소로 교환.
- 고객 공개 투영은 개발 서버 전용. 생산 빌드/API 모드에는 로컬 접수·합성 성공으로 대체 안 함. 실제 서버에서는 공통 DB와 서비스 API로 연결.
- 새 신고·응원 수신으로 숨김·검수 원문·번역·작성자 공개 범위를 덮어쓰지 않음. 사용자 삭제/비공개 우선. 복사한 개인 일정·새 본인 여행기에 원본 운영자의 작성자 ID가 남지 않도록 보완.
- 권리 철회 사진은 기본 샘플 사진으로 되살리지 않음. 고객 숨김·사진 차단·주변 제외·공개 노출 기간을 검수 투영에도 적용.
- 관리자 OpenAPI/Schema 72개 DTO, 45개 명령 형식, 4개 실제 adapter 경로, 61개 합성 fixture. 계약 형식 검사는 서버·모델 실행 완료 증거가 아님.
