## 데이터와 편집 보호

- 관리자 저장소 `spotlog.admin.review.v1` 사용. 장소 미저장 입력은 운영자별 v2 편집 저장소에 최초 편집 revision과 보관. 다른 창/재접속으로 최신 자료가 바뀌면 입력 유지·저장/공개 중단 후 명시적 최신 초안 전환
- 노출·문의·번역·AI 시험/정책 등은 운영자·편집기·대상별 로컬 임시 입력. 성공 후 정리, 오류/충돌 시 유지. API 모드의 고객 관련 원문은 기기에 자동 보관하지 않고 현재 화면에만 유지
- 저장 공간 부족·손상된 저장 자료·부정확한 API 응답은 성공으로 표시하지 않음. 기존 자료 자동 초기화 금지
- API 키·비밀번호·회원 개인 일정/메모·고객 AI 요청문/대화 원문은 관리자 DTO에서 제외. 비공개/휴지통 여행기 원문·카드도 기본 응답에서 제외. 실제 원본은 서버의 소유자 자료에 보존할 책임
- 권리 철회·폐업 자료는 현재 원본 검증에서 먼저 후보 제외. 실패한 제거 작업이나 과거 색인 복구로 후보 재등장 방지
- 사용자 휴지통은 한국 시각 달력 6개월. 복원은 비공개, 개인 일정·여행기는 독립. 공유 사진 참조가 있으면 파일 정리 차단
- 고객 화면의 별도 루트·CSS·보관 자료 유지. 모바일 상세 화면에서 목록/검색 영역 접기. 입력 16px, 목록/보조 버튼 14px, 보조 상태 12px, 기본 보조 버튼 36px. 아이콘 이름·입력 라벨·키보드 탭 이동·접힌 모바일 메뉴 접근 제외
