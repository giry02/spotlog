# 내 여행 오프라인 저장 · 2026.10.13

사용자 요청: 내 여행에 저장 기능을 추가해 오프라인으로 열기. 지도와 GPS의 지원 범위도 확인.

## 사용 순서

1. 내 여행을 열어 후보 선택과 작성을 완료.
2. DAY 버튼 아래 ‘오프라인 저장’ 한 번 선택. 저장 완료 표시까지 확인.
3. 인터넷 연결이 없어도 같은 브라우저에서 앱을 다시 열고 내 여행 선택.
4. 일정을 바꾸면 ‘저장 업데이트’. ‘저장 관리’에서 보관 시각·사진 누락·업데이트·삭제 확인.

보관본 삭제와 원래 일정 삭제는 별도. 원래 일정을 휴지통으로 옮기거나 삭제하면 해당 보관본도 정리. 후보가 남은 초안·공개 여행기·다른 사람의 여행은 다운로드 대상에서 제외.

## 저장 범위와 실패 처리

- 비공개 PLAN의 DAY/방문 ID, 방문 순서·시각·주소·개인 메모·예약 고정·진행 기록 보관. 기존 기기 저장소를 원본으로 유지하며 다운로드 파일에서 자동 복원하거나 삭제한 여행을 재등장시키지 않음.
- 검색 입력·AI 요청문·편집 복구 원문·서버 인증·운영자 자료·고객 요청 API·현재 GPS는 별도 오프라인 저장에서 제외.
- 고객 진입점에서 사용하는 JS/CSS/지도 worker를 빌드별 SHA-256으로 확인. 해당 여행의 허용된 사진만 추가. 임시 보관 후 검증된 메타데이터 포인터를 교체.
- 저장 실패·용량 부족·동시 변경·취소 시 이전 정상 보관본 유지. 사진 일부를 포함하지 못한 경우 일정 보관과 사진 누락 개수를 함께 표시.
- 브라우저가 파일을 지웠으면 다시 저장이 필요한 상태로 표시. 기능 미지원 환경은 저장 버튼 차단, 가능한 것으로 표시하지 않음.
- 고객/관리자 원래 저장소·다른 캐시를 삭제하지 않음. 다른 탭 변경과 같은 캐시 참조를 보호.

실제 배포에서는 같은 출처의 정적 사진만 포함. 기존 localhost 검수 자료는 선택한 `/@fs/.../Spotlog/assets/spotlog/` 사진과 `busan-business`, `public-tourism`의 단일 파일만 추가 허용. 원래 방문 사진 URL을 고쳐 쓰지 않으며 임의 폴더·중첩 폴더·인증 쿼리·외부 지도 파일은 제외.

## 지도·GPS

오프라인 또는 지도 연결 실패 시 저장된 좌표의 번호 위치도 사용. 장소 선택·주소·직선거리·미확인 좌표 안내 유지. 실제 도로·실시간 경로·교통·영업 정보를 보장하지 않음. 같은 좌표의 재방문 번호는 다른 방문 ID로 유지하고 320px에서도 버튼이 겹치지 않게 배치.

현재 `tile.openstreetmap.org`는 오프라인 다운로드 금지. 지도 타일을 미리 수집하지 않음. 도로 배경을 내려받으려면 오프라인 이용이 허용되는 공급자나 자체 타일 구성이 필요. [OSM 공식 정책](https://operations.osmfoundation.org/policies/tiles/).

GPS는 `OFFLINE_ROUTE_DISPLAY` 목적의 공개 위치 약관＋명시적 선택 동의＋브라우저/기기 권한 조건으로 한 번 조회. 고정밀 요청·20초 제한, 서버 전송·지속 추적·보관 없음. 다른 DAY, 화면 숨김·종료 시 위치 제거. 기존 주변 검색의 저전력·10초 조건은 유지.

현재 운영자·위치 약관이 초안이므로 실제 사용자 화면의 GPS 요청은 차단. 공개된 `locationPolicy`를 RouteMap에 전달하는 서비스 연결과 실기기 확인이 필요. 승인된 시험 약관은 DEV 격리 화면에서만 사용하며 실제 서비스로 간주하지 않음.

## 환경과 연결 전 항목

- 모바일 브라우저/홈 화면 웹: HTTPS 또는 localhost에서 검수. 앱과 동일한 출처의 저장소 이용.
- 기존 DEV 화면 `/`과 관리자 `/admin.html` 유지. 빌드 검수 `/spotlog/`만 별도 서비스 워커 범위 사용.
- 로컬 확인: http://127.0.0.1:5210/spotlog/#trips . 지도/GPS 격리 확인: http://127.0.0.1:5210/tests/offline-route.html?policy=published .
- Expo 설치형 앱: 현재 원격 WebView 구조에서 오프라인 재시작 미지원. 기능 준비 중으로 표시. 네이티브 여행·사진 보관과 전용 읽기 화면, 위치 권한 연결은 후속 작업.
- 실제 계정 동기화·AI·지도 API·서버 공개 정책은 이번 저장 기능으로 연결되지 않음. Git/public 배포 없이 로컬 검수만 진행.

## 구현 파일

`OfflineTripControl.tsx` / `offline-trips.css`: 한 번 저장·상태·업데이트·삭제·취소·목록 배지. `PersonalTrip.tsx`, `App.tsx`: 보기 화면과 기존 휴지통/저장 흐름 연결.

`offlineTrips.ts` / `spotlog-offline-sw.js`: 별도 IndexedDB/CacheStorage, 검증·원자적 교체·범위 제한·재시작 대응. `offlineShellPlugin.ts`: 고객 실행 그래프와 실제 출력 파일 해시. `offlinePreviewPlugin.ts`: 동일 localhost 출처의 빌드 검수.

`OfflineRouteMap.tsx` / `offlineRouteProjection.ts` / `offline-route-map.css`: 타일 없는 위치도·방문 선택·GPS. `RouteMap.tsx`, `NaverRouteCanvas.tsx`, `locationConsent.ts`: 온라인 실패/오프라인 분기·목적별 동의. `accountPolicies.ts`: 위치 약관 초안에 오프라인 화면 목적과 처리 범위 추가.
