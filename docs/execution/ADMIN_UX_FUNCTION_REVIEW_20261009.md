## 인기 자료와 메인 게시

**노출·추천 → 인기 자료·메인 게시 → 인기 랜드마크 / 인기 장소·업체 / 인기 여행기 → 메인에 게시 → 노출 설정·고객 미리보기**

- 고객 기준과 같은 저장 수 내림차순. 숫자는 읽기 전용, 운영자가 수치 입력·인기 조작 불가.
- 실제 집계는 `ops.popularity`의`SERVER`·집계 시각·저장 수 기준으로 전달. 로컬`SAMPLE`은 검수 수치로 구분. API모드에 서버 집계가 없으면 빈 상태, 샘플로 대체하지 않음.
- 공개 장소는`HOME_PLACE`, 공개 여행기는`HOME_JOURNAL` 기존 노출 명령으로 게시. 현재 공개본·좌표·영업·사진·사용권 검수 유지. 가상 장소는 고객 메인 게시 차단, 미검수 카탈로그는 장소 검수로 연결.
- 이미 게시 중인 항목은 중복 게시 차단, 노출 설정으로 이동. 기존 순서·제목·표지·기간을 관리하며 예약된 항목을 무조건 새로 덮어쓰지 않음.
- 고객 홈에서 명시적으로 게시한 장소만 기존 `LandmarkGuideCard`로 표시. 저장·공유·더 많은 장소 보기 연결. 게시 순서·시작/종료 시간·철회·대표 사진 조건 적용. 새로고침 없이 예약 경계에서 갱신.
- 실제 고객 서비스 게시·인기 집계는 서버 연결 후 동작. 이번 검수는 격리된 로컬 관리자·고객 화면 연결.
