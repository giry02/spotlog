# 저장한 장소로 여행 만들기

2026-09-18 사용자 요청으로 저장 화면을 두 가지 생성 방식으로 변경한다. 기존 카드·지역 필터를 유지하고, 여행 기간 선택은 하단 팝업에서 처리한다.

- **날짜별로 담기:** 기간 선택 → DAY 선택 → 기존 장소 카드에서 담기 → 일정 만들기. 직접 정한 DAY와 방문 순서를 그대로 저장한다.
- **바로 만들기:** 기간 선택 → 현재 지역 필터의 저장 장소 전부로 즉시 생성. 지역과 직선거리를 참고해 나누며 외부 AI나 실제 이동 경로를 연결한 기능은 아니다.
- 당일~3박 4일을 한 줄로 표시한다. 더 많은 일정에서 4박 5일~6박 7일을 고른다. 출발일·여행 이름은 선택 입력이다.
- 직접 담기의 DAY 선택줄은 스크롤 중에도 상단에 남는다. 다른 DAY로 이동·담김 해제·같은 DAY 내 순서 조정이 가능하다.
- 기간 축소 시 범위 밖 장소를 미배치로 보존하고 DAY 재지정 후 생성한다. 빈 DAY도 선택한 기간에 맞춰 유지한다.
- 팝업 닫기와 앱 내부 탭 이동에서 입력을 보존한다. 새로고침/브라우저 종료 후 미완성 초안 복원은 포함하지 않는다.
- 완성 일정은 기존 기기 저장소에 비공개로 저장하며, 기존 일정은 변경하지 않는다. 저장 실패 시 입력을 유지한다.

이번 반영에 미공개 랜드마크 상세보기, 2차 통합본, 일정표 변경은 포함하지 않는다.

검증: 웹 빌드 및 생성·담기·AI 초안·폰트 관련 테스트30개. 320/390/460px에서 카드·팝업·DAY 선택줄의 가로 넘침과 기존 글자 크기 유지 확인. Android 실기기 검수는 별도다.
