6개월은 180일로 바꾸지 않고 한국 시각 기준 **달력 6개월**로 계산한다. 예를 들어 8월 말일은 다음 해 2월의 마지막 날로 맞춘다. 로컬은 기기 시각에 따라 만료 항목을 숨기고 복원을 차단한다. 서버 시각 판정과 만료 자료 정리, 여러 여행이 공유하는 사진 정리는 백엔드 연결 시 구현한다.

## 3차: 새로 연결한 기능

### 추천 초안 만들기

홈의 **AI 여행 만들기**에서 지역·취향 추천 또는 저장 장소 추천을 선택한다. 기본 조건은 먼저 보여주고, 날짜·교통·속도·필수/제외/고정 장소·동행·식사·접근성은 펼쳐 입력한다.

- 1~7일, 최대 30곳. 필수 장소나 기간을 조용히 줄이지 않고 충돌·과밀·부족한 자료를 표시한다.
- 결과에서 DAY별 장소와 근거를 확인하고 일반 후보를 포함/제외한다. 음식점·숙소는 직접 선택한 경우에만 추가한다.
- 추천/저장/등록 자료 검색을 전환하며 현재 DAY와 기준 랜드마크를 이어받는다.
- **내 여행에 저장**을 눌러야 비공개 개인 일정이 만들어진다.
- 팝업을 닫았다가 다시 열면 입력·미리보기·선택을 유지한다. 브라우저 새로고침 이후 미완료 추천 입력까지 복구하는 기능은 아니다.
- 조건은 개인 일정에 보관하되 여행기로 바꿀 때 동행·식사·접근성 등의 개인 요청을 복사하지 않는다.

현재 추천은 등록 장소와 입력 조건을 조합하는 샘플이다. 실제 AI/RAG, 실시간 영업·가격·이동 시간이나 최적 경로로 표시하지 않는다.

### 일정 일부 다시 추천

내 여행의 **일정 다시 추천**에서 DAY 전체, 방문 시간이 정해진 오후, 지정 장소부터 남은 일정을 선택한다. 덜 걷기·장소 제외 조건으로 변경 전/후를 비교하고 승인한 변경만 적용한다.

필수·고정 방문, 숙소, 연결된 예약 업체, 수정 범위 밖 장소·글·사진·카드 ID는 보호한다. 원래 요청 범위와 최신 여행 버전을 적용 직전에 다시 검사한다. 취소·중복 승인·늦은 응답·잘못된 응답이 현재 여행을 덮어쓰지 않게 했다. 샘플의 ‘덜 걷기’는 방문 수를 줄이는 제안이며 실제 보행 경로 계산은 아니다.

### 여행 중 안내

내 여행의 **여행 중 안내**는 보고 있던 DAY에서 열린다. 현재 방문, 오늘 일정, 다음 장소, 볼거리, 운영 정보, 접근성, 질문을 볼 수 있다. 한글 이름·주소를 크게 띄우거나 복사할 수 있다.

등록 소개와 내 일정에서 확인할 수 없는 영업시간·대기·안전·접근성 답은 확인 필요로 표시한다. 확인일이 없는 자료에 날짜를 만들어 붙이지 않는다.

### 영어·번역·프로필

- 프로필의 **프로필·이용 설정**, 또는 여행 안내에서 한국어/영어를 전환한다. 같은 장소·DAY·일정을 유지하고 한글 이름·주소는 원문으로 제공한다.
- 홈 진입, 하단 메뉴, 저장 여행 생성, 추천 핵심 조건·행동, 관광 안내와 이용 설정에 영어를 적용했다. 기존 편집·업체 팝업 등 모든 화면의 문구가 영어로 완성된 상태는 아니다.
- 여행기 본문·사진 설명·장소 댓글에 영어 보기 기능을 연결했다. 준비된 샘플 번역은 샘플로 표시하고, 미지원 원문은 그대로 보존하며 번역이 없다고 안내한다.
- 원문·원문 버전·언어·용어 기준이 바뀌면 이전 번역을 재사용하지 않는다. 샘플을 검수 완료 번역으로 표시하지 않는다.
- 활동 이름 수정과 언어 설정, 저장→여행 생성→주변 업체→여행기의 이용 안내를 추가했다. 실제 로그인·기기 간 동기화는 서버 연결 범위다.
