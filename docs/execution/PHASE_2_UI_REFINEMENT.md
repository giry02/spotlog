# 2차 개인 일정 버튼·카드 보정

2026-09-15 · 사용자 기간 필터 버튼 크기 예시 반영 · 로컬만 적용

기존 개인 일정 카드의 ‘주변 업체’에 페이지용 `.outline` 최소52px가 남아 크게 보였다. [스타일 가이드 §4](../STYLE_GUIDE.md)의 작은 보조 행동 크기로 정리했다.

- 주변 업체: 높이52→36px, 글자14→12px/700, 모서리11px, 옅은 배경, 그림자 없음.
- 장소 추가·지도: 높이52→40px, 글자12px/700, 모서리11px.
- 카드 안쪽14→12px, 카드 사이12→10px, 행동 줄 위12→6px, 출처 위8→2px.
- 1주차 검수 장소 카드 높이 약204→160px. 연결 식당 약154→130px. 긴 주소와 메모가 있으면 필요한 만큼 늘어남.
- 장소 이름·주소·사진 출처·입력 글자는 유지. 다른 페이지와 팝업 버튼의 규격도 유지.

## 확인 주소

- [1주차](http://127.0.0.1:5201/spotlog/#trips)
- [2주차](http://127.0.0.1:5202/spotlog/#trips)

같은 주소에서 새로고침하면 보정한 디자인을 볼 수 있다. 각 주소의 여행·저장 기록은 유지했다. 1주차에는 2주차 기능이 섞이지 않는다.

## 검증과 보관

- 글꼴 회귀 검사7개, 웹 타입 검사·빌드, 1주차/2주차 개별 보관본 빌드 통과.
- 실제 iframe 뷰포트320/390/460px에서 두 버전의 카드/화면 가로 넘침0. 주변 업체 버튼36px·글자12px 확인.
- 작은 버튼에서 기존 주변 업체 하단 모달 진입·닫기 확인.
- 검수 자료: `artifacts/phase2-local-20260915/compact-plan-checks.json`, `compact-width-comparison.png`.
- 원본 `week1`, `week2` 보관본은 유지. CSS 보정본은 `.git/spotlog-phase2/week1-ui1`, `week2-ui1`에 별도 저장.
- 각 보정본의 `changes.patch`는 해당 원본 주차 위에 적용한다. `source.zip`은 전체 소스이며, `site/`는 그 소스로 새로 빌드한 화면이다.
- 보정된1주차에서 보정된2주차로 올릴 때는 `week2-ui1/from-week1-ui1.patch`를 사용한다. 원본2주차 패치와 혼용하지 않는다.
- `scripts/phase2-ui-checkpoint.mjs`는 두 원본 트리에 동일한CSS와 해당CSS import만 적용한다. 원래 Git 인덱스·브랜치·커밋은 변경하지 않는다.
- 커밋·GitHub 업로드·공개 서비스 활성화 없음.
