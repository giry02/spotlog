# 모바일 하단 메뉴 스크롤 보완 — 2026-09-27

사용자 보고: 모바일에서 위쪽으로 스크롤하다가 하단 메뉴까지 올라오는 경우 발생.

## 확인과 수정

- 기존 body는 최소 높이 100vh, 앱과 본문은 100dvh를 사용. 모바일 주소창 표시 상태에 따라 두 기준이 달라질 수 있으며, html/body의 바깥 스크롤도 허용된 상태였음. 하단 메뉴는 앱 기준 absolute이므로 바깥 스크롤에 함께 이동할 수 있는 구조.
- html/body/root의 바깥 스크롤을 차단하고 body의 실제 표시 높이를 기준으로 앱을 제한. 본문만 내부 스크롤하도록 정리.
- 본문 높이는 앱 높이에서 기존 메뉴 74px와 하단 안전 영역을 제외. 장소 안내의 과거 70px 공식을 74px로 맞춤.
- 사진·영상·상세는 앱 전체 높이 유지. 메뉴 없는 상세에는 장소 안내의 메뉴 높이 차감을 적용하지 않음.
- 데스크톱 앱 높이 900px 상한, 최대 폭 460px, 기존 버튼·폰트·색·카드 외형 유지. 개발용 스타일 가이드도 앱 높이 기준으로 스크롤.
