## 앱 개선 우선순위

최초 입력이나 확인 단계를 늘리지 않고, 이미 만든 여행을 쉽게 이어 쓰는 방향. 아래 아이디어는 이번에 구현하지 않음.

| 순위 | 제안 | 한 번의 진입·사용 효과 | 연결 구분 |
|---|---|---|---|
| 1 | 홈에서 내 여행 바로 이어가기 | `내 여행 이어가기` → 마지막 DAY·다음 방문. 여행 중 목록을 다시 찾는 과정 감소 | 기존 기능 확장. 현재 기기의 여행/진행 위치를 재사용해 프론트에서 가능. 기기 간 연결은 서버 필요 |
| 2 | 마지막 후보 확인에 비교 정보 보강 | 기존 마지막 확인에서 사진·직선거리·확인된 특징2~3개 표시. 이름만 보고 식당·숙소를 고르는 부담 감소 | 기존 기능 확장. 프론트 가능. 가격·영업·시설은 실제 관리자 자료 확보 후만 표시 |
| 3 | 다녀온 곳으로 여행기 초안 만들기 | 기존 `여행기로 남기기` → 방문 완료한 곳을 기본으로 별도 비공개 초안. 안 간 곳을 지우는 과정 감소 | 기존 기능 확장. 프론트 가능. 사용자가 포함 장소를 확인하고 공개하는 기존 흐름 유지 |

| 후속 | 여행 한 건 오프라인 준비 | `오프라인 준비` → 연결이 끊겨도 일정·주소·확보한 사진 열람 | 기기 저장만으로 앱 재실행까지 보장되지 않음. 캐시·버전·재실행·실기기 검증 필요. 지도/검색은 별도 |
