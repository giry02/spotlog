# 신고 진입 통합 · 2026-10-06

사용자 요청: ‘여행기 신고에 표지신고에 그냥 아래 신고 하나 넣고 다 빼 그리고 깃에 올려’.

- 여행기 상단의 여행기/표지 신고, 사진별 신고, 장소 카드의 장소/사진 신고, 작성자 옆 신고, 댓글별 신고 버튼 제거.
- 여행기 본문 맨 아래에 작은 ‘신고’ 버튼 하나 배치. 개인·삭제·계획용 여행기에는 제공하지 않음.
- 기존 하단 팝업에서 신고 대상→이유→선택 상세 사유 입력. 대상은 여행기·작성자 / 장소 / 사진 / 댓글·답글로 묶음. 기본 대상은 여행기 전체.
- 모든 DAY의 실제 장소·사진·댓글 ID와 여행기/카드 맥락 유지. 같은 장소를 다른 DAY에서 방문하면 해당 카드별 대상을 유지. 사진 출처와 사용 범위 문맥 유지.
- 본인/삭제/숨긴 댓글과 다른 여행기 댓글은 대상에서 제외. 개인 일정·메모를 운영 데이터에 추가하지 않음.
- 대상 변경 시 작성한 이유/상세 입력 유지. 접수 중 선택 잠금, 기존 중복 접수/실패 재시도/연결 전 상태 유지.
- 발견·장소·주변 업체의 공용 신고도 ‘신고’ 하나로 통합하고 사진/장소 구분은 팝업 안으로 이동.
- 좋아요·좋아요 목록·댓글·답글·수정·삭제 및 기존 저장 자료 유지. 서버/API 연결 상태 변경 없음.

## 확인

- TypeScript/Vite 고객 빌드 성공.
- 신고 대상 ID/사진/댓글/비공개 제외/실제 접수 형식, 기존 공개 자료·신고 계약 및 폰트 **28검사 통과**.
- 격리 Edge320/390/460px에서 여행기 신고 버튼 정확히1개, 상단·장소·사진·작성자·댓글의 중복 버튼0개 확인.
- 신고 대상 변경 후 이유/상세 유지, 입력16px·가로 넘침 없음, 미연결 운영 빌드 접수 비활성 확인.
- 로컬 검수에서 표지 사진 선택→저작권 신고 접수 시 실제 사진ID·출처·여행기 맥락 유지.
- 원래 로컬 검수본에도 같은 변경 반영. 관리자 소스는 업로드/배포 제외.

Git 공개 브랜치 `codex/mobile-foundation`에 반영 후 기존 GitHub Pages 배포로 공개 사이트 갱신. 실제 공개 검수 결과·커밋·배포 작업은 로컬 현재 인수인계에 기록.
