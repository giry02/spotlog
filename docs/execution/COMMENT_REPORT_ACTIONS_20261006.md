## 적용 내용

- 공개 여행기 전체 댓글, 장소 카드 댓글·답글에 작은 깃발 아이콘 제공. 다른 사용자 댓글에만 표시.

- 아이콘을 누르면 해당 댓글 대상으로 신고 팝업 바로 열기. 여행기·카드·댓글·답글 부모 ID 연결 유지.
- 카드 댓글 팝업은 먼저 닫고 신고 팝업으로 전환. 팝업 중첩 방지, 작성 중 댓글은 다시 열면 유지.
- 여행기 전체 신고는 본문 맨 아래 하나 유지. 상단·표지·장소·사진·작성자 중복 신고 버튼은 다시 추가하지 않음.
- 개인 여행과 기존 저장 자료는 변경하지 않음. 관리자 소스는 이번 업로드에서 제외.
