## 첫 오픈 범위

- 발견·저장·사진 갤러리, 여행/DAY·글/사진 편집, 주변 업체·숙소·지도, 카드별 소통, 계정과 앱을 포함한다.
- AI는 **기본 당일 추천과 승인 후 여행 저장**까지 포함한다. 수동으로 여러 DAY를 편집하는 기능은 유지한다.
- 복잡한 다일 자동 최적화, DAY/오후 부분 재생성, 대화형 관광 안내, 영어 UI·자동번역 확장은 후속 기능이다.
- 초기 자료는 **1개 지역·장소/업체 약 100건**을 산정 전제로 한다. 기존 순위를 연결하며 순위 산식 연구나 전국 자료 수급은 포함하지 않는다.
- 기존 화면·앱 구조와 관리형 서버/외부 모델 API를 활용한다. 자체 GPU 모델 운영·학습과 앱 전면 재작성은 별도 범위다.
- 프론트 기간의 화면은 예시 응답을 사용한다. 실제 서버·AI와의 화면 연결은 01/27부터 진행한다.
- 백엔드에서 내부 업체 ID·순위·주소·좌표를 연결하고 AI/RAG는 같은 ID의 자료를 사용한다. 네이버 검색 결과를 자동으로 RAG 원천에 적재하지 않는다. 현재 지도와 네이버 검색 연결은 구분하며 지도 공급자 전면 교체는 포함하지 않는다.

## 일정 적용 기준

초기 업체 원천과 순위 자료, 서버·외부 API 계정, 앱 배포 계정과 시험 기기가 준비되는 전제다. 원천 자료가 불완전하거나 서버 기반을 모두 새로 만드는 경우 백엔드 6주 범위를 다시 산정한다. 이전 단계가 늦어지면 다음 단계 시작일도 함께 조정한다.

02/02부터 시험 버전 제공을 목표로 한다. 적용 대상 신규 개인 Google Play 계정의 12명·14일 연속 참여와 프로덕션 접근 권한은 실제 충족 여부를 확인한다. 제출·심사·승인·공개는 별도 상태이며 03/02 공개는 앱 승인과 출시 조건 충족에 따른 목표다. [Google Play 테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)

화요일마다 해당 기능 버전을 기준으로 공유한다. **02/09는 설 연휴이므로 02/05 사전 공유**로 대체한다. 03/01 휴일을 반영해 공개 준비는 02/26까지 진행한다. 일정 계산에서 제외한 평일 휴일은 2026-09-24·09-25·10-05·10-09·12-25, 2027-01-01·02-08·02-09·03-01이다. [2026년 월력요항](https://www.kasa.go.kr/prog/bbsArticle/BBSMSTR_000000000010/view.do?bbsId=BBSMSTR_000000000010&nttId=B000000001860Pe2zT3), [2027년 월력요항](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=431)
