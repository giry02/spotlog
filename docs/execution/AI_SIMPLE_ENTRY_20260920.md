# AI 여행 만들기 최초 입력 간소화

2026-09-20 · 로컬 반영. 사용자 제공 GitHub 공개 화면을 초기 입력의 기준으로 삼았다.

- ‘지역·취향 추천’ / ‘저장 장소로 추천’ 두 모드 유지.
- 요청문장과 예시문장, 항상 보이는 지역·기간·여행 속도·이동수단 선택, 하단 ‘초안 만들기’로 정리.
- 날짜·도착/출발 시간, 필수·제외·고정 장소, 동행·식사·접근성 입력 및 세부 조건 펼침 제거.
- 공통 입력 16px/400, 기존 폼 간격18px과 하단 팝업·버튼 역할 재사용.
- 기존 초안에 남은 제거 대상 입력은 최초 입력 또는 ‘조건 바꾸기’ 진입 시 정리. 문장과 화면에서 선택한 지역·기간·속도·이동수단·추천 모드는 유지.
- 이미 생성된 미리보기의 날짜·예약·업체 선택은 복원 및 저장 시 그대로 유지. 결과의 하루 흐름과 일정 수정도 유지.
