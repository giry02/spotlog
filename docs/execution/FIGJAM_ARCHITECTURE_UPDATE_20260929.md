## 현재 기본 경로

간단 입력 또는 저장 장소로 추천 → 우리 서버 → 맥미니 소형 LLM 조건 해석 → 서버 조건 검증 → 우리 DB·RAG 후보·근거 검색 → 서버 일정 계산 → 소형 LLM 설명 → 서버 최종 검증 → 고객 확인·저장.

- 직접 선택한 조건은 그대로 전달. 원문·추가 요구·선택 출처 보존.
- RAG 검색은 우리 검색 기능 담당. 임베딩 AI는 검색용 벡터 변환, 언어 모델은 조건 해석·설명 담당.
- Jev는 고정 항목 분류의 선택 비교 후보. 기본 흐름에 필수 아님. Jev 자체가 우리 RAG DB를 검색하는 구조 아님.
- Jev 비교 시 같은 한국어 요청·자료로 정확도·누락률·전체 초안 시간·비용 측정. 호출 추가만으로 빨라진다고 가정하지 않음.
- 대형 LLM은 근거가 충분한 소형 모델 실패 부분만 보완. 데이터 부족·지도 장애·정보 부족은 별도 대응.
- 챗봇은 향후 같은 생성·검색·검증·저장 기능을 재사용하는 진입점.
- 맥미니 64GB·기존 Flowise는 사용자 확인. 로컬 모델·Ollama·pgvector는 설치·실측 전 제안. 실제 AI/RAG 구축 중단 상태 유지.
