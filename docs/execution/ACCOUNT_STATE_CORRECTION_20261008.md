# 계정 상태·일반 회원가입 수정·검수 · 2026.10.08

후속 사용자 요청으로 가입 순서를 **약관 먼저 → 정보 입력 화면에서 이메일 인증까지**로 변경. 아래 검수 기록은 당시 상태의 이력이며, 최신 가입 화면과 검수는 [인라인 가입 수정](ACCOUNT_SIGNUP_INLINE_20261008.md) 참조. 회원 상태·기기 자료 분리 기준은 유지.

사용자 지적: 비로그인인데 새싹 기록자·회원 정보와 로그인 버튼이 함께 표시됨. 일반 가입이 없고 소셜만 있음. 화면의 회원 여부를 기기 프로필과 별개로 처리해 기본 상태가 맞지 않았음. 일반 가입을 기본으로 복원하고 관련 흐름을 함께 수정. 로컬 검수본 반영이며 Git 업로드·공개 사이트 배포 없음.

## 연결 전 항목

- 이메일 발송·가입/인증·비밀번호 해시·로그인 세션·만료/정지·삭제 처리 서버, Google/Apple 제공자 설정. 인증어댑터 기본 미설정: 실제 가입·발송·로그인 요청 없음.
- 계정별 찜/여행/댓글/반응 서버 저장, 실제 회원 프로필·등급·통계·알림, 기기 자료 명시적 가져오기. 현재 회원 검수 fixture의 댓글/응원도 기기 미리보기로 구분.
- 비밀번호 재설정 링크 검증·변경 완료와 전체 세션 폐기. 소셜 계정 연결·추가 로그인 방식 연결은 각 계정을 검증하는 별도 기능.
- 운영자 정보·정식 약관·국가별 가입 기준 확정. 문서5종은 `2026-10-08.draft-2`, 운영자명/주소/이메일 미정. GPS는 가입 필수 제외, 위치 기능 선택 때 별도 동의/OS 권한; 이번 수정에서 GPS 수집 없음.

현재 계정 API 타입: `web/src/socialAccountService.ts`, 전역 상태: `AccountProvider.tsx/accountContext.ts`. [백엔드 연결 계약](../contracts/account-v1/README.md), [정상·인증대기·실패 샘플](../contracts/account-v1/fixtures.json). 본문에 없는 서버 기능을 실제 처리 완료로 전달하지 않음.
