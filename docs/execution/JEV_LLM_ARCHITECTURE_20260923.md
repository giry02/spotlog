## 기본 흐름

고객 글·선택값 → 우리 서버 → 외부 Jev 판별 → 서버 조건 검증 → 우리 DB·맥미니 RAG 검색 → 서버 일정 계산 → 맥미니 소형 LLM 설명 → 서버 최종 검증 → 고객 확인·저장.

| 담당 | 맡는 일 | 맡기지 않는 일 |
|---|---|---|
| 외부 Jev | 요청 종류, 정해둔 지역·기간·속도·교통·포함/제외 판별 | 자유로운 설명 작성, 없는 업체·좌표 생성, 여행 저장 |
| 우리 서버 | 원문·선택 출처 보존, 조건 검증, 후보 제한, 일정 계산, 보완 판정, 저장 | Jev 판별을 검증 없이 확정 |
| 우리 DB | 장소 ID·주소·좌표·순위·예약의 기준 | 의미 검색 점수로 공식 순위 대체 |
| 맥미니 RAG | 허용 장소의 설명·특징 근거 검색 | 외부 검색 자료 무조건 적재 |
| 맥미니 소형 LLM | 검증된 일정의 짧은 설명, Jev 미분류·복합 요구의 필요한 부분 해석 | 정상 판별 전체 반복, 좌표·영업 사실 추측 |
| 외부 대형 LLM | 근거가 충분한 소형 모델 실패 부분 보완 | 입력·자료 부족이나 연결 장애를 사실 생성으로 우회 |

Flowise는 맥미니의 모델·검색 실행 도구. Ollama는 로컬 모델 실행 프로그램. 둘 다 AI 모델명과 구분. Jev 호출은 우리 서버의 판별 어댑터가 담당하는 제안. 브라우저에 Jev 키·맥미니 주소 직접 전달 제외.

## 판별 규격과 원문 보존

- 서버에서 원문, 직접 선택값, 기본값 여부, 저장 장소 ID, 기존 예약·일정 버전 보존.
- Jev 질문은 항목별 선택지와 미분류·미입력·충돌 상태를 함께 설계. 정해둔 항목은 한 요청에 묶어 판별.
- 응답을 원문 전체의 완전한 의미 추출 결과로 간주하지 않음. 새로운 가게명·자유 표현·DAY별 예외는 원문과 별도 추가 요구로 보존.
- 미분류·복합 요구는 필요한 원문과 정상 판별값을 맥미니 소형 모델에 전달 → 서버 재검증. 정상 항목 전체를 다시 해석하는 호출은 생략.
- 핵심 입력이 실제로 없으면 기존 화면에서 필요한 항목만 확인. 임의 추측 또는 대형 호출로 대체 금지.
- 직접 선택한 값은 재분류 불필요. 문장과 직접 선택이 충돌하면 해당 항목만 확인. 화면 기본값이 명시적 문장을 덮지 않게 구분.
- Jev 확신도는 보조 신호. 한국어 평가 결과·입력 근거·서버 제약 검사 없이 확신도 하나로 최종 결정 금지.
- 소형 LLM의 설명 입력은 검증 일정 + 필요한 근거 + 관련 원문. 임베딩·RAG 검색도 네 가지 대표 항목 밖의 취향·예외를 유지.

예시: “부산 2박 3일, 렌터카로 여유롭게. 식당은 넣고 숙소는 예약했으니 빼줘.”

판별 목표: 생성 / 부산 / 3일 / 자동차 / 여유 / 식당 포함 / 숙소 추천 제외. 서버에서 기존 예약 유지. 2박→3일 계산은 코드 검증. 이는 기대 정답 예시이며 Jev 실측 응답 아님.

## 내부 연결 규격 보완

기존 세 규격의 역할 유지, 기본 해석 호출 위치 변경.

| 연결 | 보냄 | 받음 |
|---|---|---|
| 서비스 서버의 Jev 어댑터 | 필요한 원문·선택 요약, 판별 질문·선택지 | 판별값·확신도·미분류 상태. 서버가 공통 조건으로 정규화 |
| /internal/ai/interpret · 미분류 때만 맥미니 | 원문·미분류 부분·정상 조건·수정 가능 범위 | 조건 변경 제안·입력 근거·미해결 항목 |
| /internal/rag/search · 맥미니 | 선호 원문·확정 조건·허용 ID·자료 버전 | 장소 ID·문서/조각·근거·색인 버전 |
| /internal/ai/explain · 맥미니 | 검증된 일정·근거·관련 원문 | 짧은 설명·근거 ID·미확인 항목 |

위 경로와 필드는 협업 제안. 현재 배포 API 아님. 자료·장소 ID·기존 여행 버전의 기준은 계속 백엔드.

## 대형 보완과 장애

- Jev 미분류 → 소형 해석 → 서버 검증 순서. 단순 미분류만으로 곧바로 대형 호출하지 않음.
- 소형 해석·표현 실패 중 충분한 입력·근거가 있는 부분만 대형 보완 대상. 기존 요청당 최대 1회는 초기 제안 유지.
- 조건을 보완했다면 후보 검색·일정 계산부터 영향 범위 재검사. 설명을 보완했다면 검증된 설명만 병합.
- Jev·맥미니·지도 연결 장애: 입력·정상 결과 보존, 재시도 안내. 대형 모델로 자동 장애 우회 없음.
- 등록 자료·좌표 부족: 미확인·자료 보완. 없는 사실 생성 금지.
- 향후 챗봇도 같은 판별·검색·일정·검증 기능 사용. 지금 간단 입력 UI 확대 없음.

## 속도 확인 기준

Jev를 붙인 사실만으로 속도 개선을 보장하지 않음. 같은 자료·같은 요청·같은 결과 품질 조건에서 비교.

- 비교 A: 로컬 LLM 조건 해석 → 검색·일정 계산 → 설명.
- 비교 B: Jev 조건 판별 → 필요한 부분만 소형 해석 → 검색·일정 계산 → 설명.
- 기록: Jev 왕복, 미분류 해석, 검색, 경로 조회, 설명, 검증, 전체 초안 완성 시간, 비용.
- 품질: 한국어 항목별·요청 전체 정답률, 제외·예약 위반, 원문 요구 누락, 추가 질문 횟수.
- 지연: 대표값과 느린 요청 구간(p50/p95), 단일·동시 요청 조건을 함께 기록.
- 줄인 LLM 처리 시간이 Jev 왕복·추가 처리보다 커야 속도 개선. 같은 LLM 작업을 그대로 유지하면 더 느려질 수 있음.
- 정확도·응답 시간·절감률 실측 없음. Qwen 4B/9B와 Jev는 평가 후보, 채택·설치 완료 아님.
