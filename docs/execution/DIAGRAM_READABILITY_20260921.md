# 구성도 가독성 기준과 개정 기록

2026-09-21 · 사용자 검토 반영 · FigJam 00~10 전체 검수

## 적용 기준

- 한 상자에 대표 행동 또는 구성 요소 하나
- 제목은 크게, 담당·연결 대상은 짧은 보조 줄로 분리
- 긴 정책 문장은 상세 문서로 이동
- 기본 흐름과 예외 흐름은 다른 구역으로 분리
- 판단은 마름모, 처리·구성은 사각형
- 화살표는 요청·반영·분기 의미가 있을 때 사용
- 같은 단계는 같은 높이·간격·읽는 방향 유지
- 기능별 구역에 A·B·C 또는 단계 번호 사용
- 고객 설명용 핵심 관계와 개발용 필드·연결 수를 분리
- 내부·외부·자체 운영을 이름이나 보조 줄에 표시

기존 번호·상위 FigJam 영역 ID·링크 유지. 구역별 표현으로 재편했으므로 기존 문서의 Mermaid 원고는 상세 연결·정책 근거이며 최신 화면 배치를 그대로 재현하는 원고는 아님.

## 보존한 설계 방향

- 간단 생성 우선, 챗봇 향후 추가
- 소형 모델 기본, 충분한 근거가 있는 실패 부분만 대형 보완
- 양쪽 모델의 결과는 우리 서버에서 검증
- 내 여행은 비공개, 여행기는 별도 공개 기록
- 저장 장소 추천·직접 DAY 담기·AI 바로 생성 유지
- 장소 ID를 기준으로 좌표·순위·사진·설명 연결
- 휴지통 6개월, 사용자 백업 기능과 장애 복구 백업 구분
