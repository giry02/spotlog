# 2차 로컬 구현과 주차별 보관

기준일: 2026-09-15 · 2주차 주요 기능 구현/검수 · 원격 업로드/활성화 없음

**최신 결과는 [2차 구현 내용과 확인 링크](PHASE_2_RESULTS.md)를 우선한다.** 아래 1주차는 먼저 보관한 시점의 기록이며 2주차 내용도 구현했다. 휴지통 정책 확인과 실제 기기/서버 검수는 남아 있다.

## 1주차 — 저장으로 여행 만들기와 주변 업체 담기

- 저장 화면의 기본 행동을 장소 선택 → 개인 일정 생성으로 연결함. 제목은 선택 입력, 기간은 생성 모달에서 한 번 고름. 글 없이 DAY별 뼈대를 생성함.
- 새 개인 일정과 기존 여행기를 용도로 구분함. 내 여행 목록에서 내 동선과 이전 작성 기록을 나눠 보여주고, 기존 본문/사진은 보존함.
- 랜드마크의 ‘주변 업체’ 하단 모달에서 가까운 맛집/카페 예시를 바로 보여줌. 담기를 누르면 해당 랜드마크 다음에 삽입하고 자동 저장함.
- 랜드마크와 연결 업체의 기본 순서 이동, 업체 유지/함께 제거, 현재 DAY에 저장한 랜드마크 추가를 연결함.
- 개인 일정은 고정 DAY/방문 ID를 유지함. 선택 실패·중복·기준 방문 상실·누락 좌표를 처리함.

검증: 기존 검사 포함 78개 통과, 웹 타입 검사/빌드 통과. 별도 검수 주소에서 협재해수욕장·오설록 저장 → 당일 개인 일정 → 수우동 담기 → 새로고침 후 세 방문 순서 유지 확인. 320/390/460px의 개인 일정 가로 넘침 0. 주변 모달 390px 외형 확인. 실제 Android 기기 터치/키보드는 미검증.

검수 기록: `artifacts/phase2-local-20260915/week1-checks.json`, `week1-plan-{320,390,460}.png`, `week1-nearby-390.png`.

주차별 보관은 `scripts/phase2-checkpoint.mjs`로 로컬 Git 객체의 트리·순차 적용 패치·소스 압축본·정적 화면 사본을 남김. 커밋이나 원격 push를 수행하는 도구가 아님. 저장 위치와 트리 해시는 `.git/spotlog-phase2/week1/manifest.json`에 기록됨.

## 2주차 — 후속 구현 결과

주변 업체 검색·직접 등록·저장 목록·상세 왕복, 숙박일/연박/예약 고정, DAY 이동·독립 복사·변경 취소, 지도 선택/오류 처리, 별도 여행기·사진 여러 장·작성 중 복구·미리보기, 카드별 반응·댓글·답글을 구현했다. 자동 검사 94개와 웹 빌드 통과. 세부 검수와 주차별 링크는 위 결과 문서를 따른다. 휴지통은 보관 정책 응답 대기이며 기존 복구 불가 전체 삭제 진입을 제거했다.
