## 보존·저장 경계

- AI 작성 초안은 사용자 식별 키와 버전을 갖는 별도 저장 항목이다. 휴지통의 6개월 정책을 적용하지 않는다.
- 손상되거나 다른 버전인 초안은 자동으로 덮어쓰지 않는다. 화면의 ‘새 초안으로 시작’을 통해 명시적으로 초기화한다.
- 장소/업체 정보가 바뀌면 기존 선택은 보여 주되 새 초안을 생성하기 전에는 저장하지 않는다. 저장 직전에도 다시 확인한다.
- 저장소 오류는 화면에 알리고 메모리 입력을 유지한다. 성공적으로 저장한 여행 ID를 다시 확인해 오래 남은 초안을 중복 저장하지 않는다.
- 관광 안내의 닫기 복원은 같은 브라우저 실행 세션 범위다. AI 작성 초안과 달리 새로고침 복원이라고 설명하지 않는다.
- 서버 계정 동기화와 앱 저장소 연동은 후속 작업이다. 브라우저 데이터를 삭제하면 로컬 초안도 사라진다.

## 검수 결과

자동 검사 **200개 통과**, 웹 TypeScript/빌드와 Expo TypeScript 통과. 변경 파일의 공백 검사 통과. 기존 MapLibre 등을 포함한 큰 번들 경고는 남아 있으며 이번 동작/화면 수정과 별도다.

실제 로컬 브라우저에서 확인한 흐름:

1. ‘제주 2박 3일 바다를 보며 천천히’ 한 문장 → 3 DAY 초안.
2. 숙소 1박 담기 → 2박 변경 → DAY 2 증가, 총 5곳 → 6곳. 새로고침 후 같은 숙박과 장소 수 복원.
3. 직접 카페 입력 도중 새로고침 → 업체명/주소 복원 → DAY 1 랜드마크 다음에 담기 → 7곳 비공개 일정 저장. 성공 후 새 AI 입력은 빈 상태로 시작. 이 검수에서 새로 만든 7곳 여행만 정리하고 이전 4개 여행은 유지.
4. DAY 1 호텔 → DAY 2 다른 직접 등록 숙소 → DAY 1 호텔과 총 6곳 유지.
5. 서울 당일 여행 → 음식점 후보 없음 → 같은 초안의 직접 담기 진입.
6. 직접 고른 제외 장소 → 자동 방문 감소 해제 → 제외 선택 유지 → 변경 전후 비교. 고정 숙소 유지.
7. 결과/상세 펼침/직접 등록을 320·390·460px에서 확인. 가로 넘침 없음. 확인한 보조 버튼36px/12px, 입력16px/400, 닫기44px 유지. 직접 등록 제목이 고정 DAY 줄에 가리지 않도록 스크롤 여백 보완.
