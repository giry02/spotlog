# 2차 장소 카드 댓글 위치와 아이콘 정정

2026-09-15 · 사용자 첨부 화면의 글 아래 반응 줄·텍스트 메뉴 수정 요청

## 최신 보완 — 최신순과 프로필 아이콘

- 장소의 최상위 댓글은 작성 시각 최신순이며, 같은 시각이면 나중에 등록한 댓글부터 표시한다. 답글은 부모 아래에서 먼저 쓴 순서로 유지하고, 수정 시 원래 위치를 유지한다.
- 새 댓글 등록 성공 시 팝업을 맨 위로 이동해 방금 쓴 내용을 보여준다. 댓글 더 보기도 최신순 묶음 기준이다.
- 기존 프로필의 ‘내 아이콘 바꾸기’로 등록한 이미지/이모티콘 이미지를 댓글·답글·좋아요 목록에 표시한다. 기존 작은 아바타34px를 재사용하고, 내 과거 댓글도 현재 프로필을 따른다. 아이콘이 없거나 로드에 실패하면 이름 첫 글자를 표시한다.
- 새 댓글의 작성자 아이콘을 함께 보관하며, 아이콘 없는 기존 데이터도 그대로 읽는다. 별도 이모지 선택기는 추가하지 않았다.
- 관련 상태·글꼴 검사21개 및 웹 타입/빌드 통과. 실제 UI에서 등록→최상단, 답글2개 작성순, 과거 댓글 수정 위치, 프로필 업로드→기존 댓글 반영, 새로고침을 확인했다.320/390/460px에서 아이콘34px·입력16px·가로 넘침0. 검수 자료 `artifacts/phase2-local-20260915/comment-profile-checks.json`과 `comment-profile-widths.png`.
- 최신5202 보관본은 `week2-ui3`이며, `changes.patch`는 `week2-ui2` 위에 적용한다. `from-week1-ui1.patch`는 보정된1주차 위에 직접 적용한다. 이전 보관본 유지, GitHub 업로드/서비스 활성화 없음.

- 여행기 읽기의 TEXT/IMAGE 블록 아래에 붙던 좋아요·댓글 버튼을 제거했다.
- 실제 PLACE 카드 안에만 반응 줄을 넣었다. 랜드마크·식당·카페·숙소에 적용하고 장소가 없거나 작성 미리보기인 카드에는 표시하지 않는다.
- 팝업 제목과 접근성 이름에 장소명을 넣었다. 예: ‘협재해수욕장 댓글 2’.
- 답글·수정·삭제는 각각 되돌림 화살표·연필·휴지통 아이콘으로 표시한다. 아이콘16px, 버튼36×36px, 마우스 설명/접근성 이름을 제공한다. 신고도 같은 아이콘 방식이다.
- 댓글 수정 권한과 삭제 확인은 유지한다. 개인 동선 화면에 소통 버튼을 추가하지 않는다.
- 저장 키는 기존 여행ID+카드ID를 유지한다. 이전에 글/사진에 저장된 시험 댓글을 지우거나 임의의 업체로 옮기지 않는다. 업체의 여러 여행에 걸친 통합 리뷰는 별도 서버 설계 범위다.

## 확인

- 협재해수욕장 댓글 작성 → 답글 아이콘 → 수정 아이콘 → 삭제 확인/취소 → 새로고침 후 유지.
- 협재 카드만 좋아요1/댓글2, 식당·다른 랜드마크·숙소는 각각0. 글/사진 반응 줄0.
- 320/390/460px 팝업 가로 넘침0, 입력16px, 아이콘 버튼36px 및 label/title 확인.
- 관련 상태·글꼴 검사19개와 웹 타입 검사/빌드 통과.
- 검수 자료: `artifacts/phase2-local-20260915/place-social-checks.json`, `place-social-widths.png`, `place-comment-icons.png`.
