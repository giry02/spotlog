# Spotlog 로그인 회원가입 5가지 방식 적용

로그인과 회원가입을 별도 첫 화면으로 분리. 두 화면에서 카카오·네이버·Google·Apple·이메일 선택. 이메일 검수 로그인 유지. 소셜 인증·이메일 가입 완료는 실제 서버 응답으로만 확정하며, 현재 업체 인증·메일·회원 서버는 연결 전. 후속 ‘깃에 올려’ 요청에 따라 이번 인증 변경을 기존 공개 브랜치와 Pages에 반영. 관리자·오프라인 저장의 별도 로컬 후속 변경은 제외.

## 화면과 동작

| 진입 | 다음 단계 |
|---|---|
| 내 계정 → 로그인 | 5가지 로그인 방식 선택 |
| 내 계정 → 회원가입 | 5가지 가입 방식 선택 |
| 이메일 로그인 | 이메일·비밀번호 → 서버 확인 → 원래 화면 |
| 이메일 회원가입 | 약관 → 활동 이름·이메일·비밀번호·확인·인증번호 → 서버 확인 → 원래 화면 |
| 소셜 로그인·회원가입 | 선택 제공자 인증 → 서버의 기존 회원/가입 대기 판단 |
| 기존 회원 | 유효한 Spotlog 서버 세션이면 로그인 상태 자동 복원 |
| 소셜 신규 회원 | 제공자 인증 완료 후 필수 약관 동의 → 서버 가입 완료 |
| 계정 관리 | 로그인 회원만 계정 정보·로그아웃·탈퇴 표시 |

카카오·네이버 시작 요청에 가입/로그인 의도 추가. Google·Apple도 같은 계약 사용. 제공자에 로그인됐다는 사실만으로 Spotlog 가입을 완료하지 않음. 이미 가입한 사람이 회원가입으로 진입해도 서버가 기존 회원이면 중복 가입 대신 로그인. 처음 방문한 사람이 로그인으로 진입하면 서버 가입 대기 상태에서 동의 확인.

이메일 가입의 약관↔정보 이동은 입력을 메모리에 유지. 다른 방식으로 전환·닫기·완료하면 비밀번호·확인·인증번호 해제. 새 세션의 회원 ID나 가입 대기 제공자가 바뀌면 이전 요청을 취소하고 동의·탈퇴 확인·입력 초기화. 같은 회원의 세션 재확인은 관리 화면 유지. 가입 대기 취소는 서버 대기 세션 종료 후 가입 방식 선택으로 복귀.

## 로컬 서버와 설치 앱

- `http://127.0.0.1:5210/#profile`: 실제 DEV 고객 화면. 기존 이메일 검수 계정이 입력된 로그인 확인 가능.
- `http://127.0.0.1:5210/spotlog/#profile`: 배포용 빌드 검수. 검수 계정 포함 안 됨.
- `http://127.0.0.1:5210/tests/account-methods.html#profile`: 격리된 인증 흐름 QA 진입점. 별도 시험 서버 응답이 없으면 실제 가입되지 않음.

꺼져 있던 5210 Vite 서버 재시작 후 HTTP200 확인. 현재 `eas.json` preview/production 웹 주소는 `https://giry02.github.io/spotlog/`. 해당 설정으로 설치한 앱은 PC 로컬 서버가 꺼져도 인터넷으로 공개본 조회 가능. 실제 설치 빌드·버전은 별도 확인 필요. 공개본은 아직 이번 변경 전 버전이며 로컬과 구분.

설치형 WebView의 소셜 인증은 시스템 브라우저 인증·앱 복귀·서버 세션 전달 연결이 남음. 외부 브라우저의 로그인 쿠키가 WebView에 자동 공유된다고 가정하지 않음. 연결 전 앱에서는 안내와 이메일 로그인 경로 유지.

## 서버 연결 작업

[5가지 인증 계약과 제공자 설정](../contracts/account-v1/README.md), [OpenAPI](../contracts/account-v1/openapi.json), [응답 샘플](../contracts/account-v1/fixtures.json)로 전달.

서버에서 회원·제공자 식별값·이메일 인증·약관 버전 관리, state/인증 코드 검증, 신규/기존 회원 판단, Spotlog 세션 발급. 제공자 콘솔의 앱/클라이언트와 callback 주소 설정 필요. 이메일은 발송·인증번호 검증·비밀번호 해시·재설정 구현 필요. 프론트에 키·회원 인증 토큰·비밀번호 보관 없음. 자동 로그인은 유효한 서버 세션 조회 결과로 확정.

운영자명·주소·문의 이메일 미정으로 현재 약관은 초안 유지. 정식 약관과 서버 연결 전 실제 신규 가입·동의 기록·인증 메일 완료를 표시하지 않음. 현재 이메일 검수 계정은 실제 회원과 분리.
