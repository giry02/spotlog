## 실제 LLM 검수 기록

새 합성 메모리 세션만 사용해 실제 `/api/chat`에서 최종 7개 의미 검사를 통과했다. 장소 좋아요·여행기 전체 댓글·응원·내 프로필·기기 활동의 정확한 앱 target-entry 5개, 등록 관광지 3개의 DAY 1 정반대 정렬, 부정/방법 설명 요청의 무변경 2개다. 실제 mode는 Flowise 2개·대형 모델 5개다. 모든 경우 저장 원본·오프라인 사본·이전 대화 이력을 보존했고, 정렬에서도 다른 DAY·각 방문의 메모·시간·체류시간을 그대로 유지했다.

최초 정렬 요청은 보호 절의 “DAY 2 … 그대로 유지”까지 추가 변경 대상 DAY로 잘못 센 검증 때문에 `MODEL_ACTION_INVALID` 502로 실패했다. 이 실패를 삭제하지 않았다. 보호 절의 DAY와 실제 정렬 대상 DAY를 구분하는 제한된 수정과 회귀 검사를 거친 뒤 **같은 원문**으로 별도 재검수하여 해결했다. 실제 다중 DAY 변경을 허용하는 완화는 하지 않았다.

- 최초 5개 통과와 정렬 실패: `work/handoff/remaining-real-llm-20261019/remaining-features-results.json`
- 동일 정렬 원문과 부정/설명 2개 재검수: `work/handoff/remaining-real-llm-20261019/registered-day-order-results.json`
