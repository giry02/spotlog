# 2026-10-16 로컬 챗봇 수정·검증

접속 주소는 http://localhost:3001/ 이다. 현재 PC에서 `npm run local:start`로 기존 Ollama·Flowise·RAG·Moa 서비스를 시작하거나 준비 상태를 확인한다. 다른 PC나 외부 인터넷에 공개하는 설정은 하지 않았다.

처음 점검할 때 네 서비스 모두 꺼져 있어 브라우저의 `Failed to fetch`를 재현할 수 있었다. 종료 원인은 확인하지 못했다. 서비스를 복구하고, 이미 켜진 프로세스를 재사용하는 실행 명령을 추가했다. 반복 실행 시 포트 소유 프로세스가 유지되는 것도 확인했다.

기본 모델은 Flowise의 로컬 Qwen3 8B이며, 검색 자료 부족이나 기본 모델의 보완 요청에는 Gemini `gemini-3.6-flash`를 사용한다. 실제 자료 부족 질문에서 Gemini 응답과 `rag-insufficient` 전환을 확인했다. 자료가 없는 답변은 일반 지식으로 안내하며 검증되지 않은 장소 카드나 가짜 근거를 만들 수 없다. 기존 로컬 Qwen3 14B는 설치·생성 검증이 끝난 대안으로 남아 있고 현재 선택된 보완 제공자는 Gemini다.

Gemini 3.8 Flash 연결 시험은 HTTP 503이었고, 3.6 Flash는 실제 JSON 연결 시험과 앱의 자동 전환 시험에 성공했다. 키는 Git에서 제외한 서버 설정에만 저장했으며 보고서와 브라우저 응답에는 기록하지 않았다. 결제 계정·유료 요금제·카드 설정은 변경하지 않았다. 3.6 Flash는 [무료 사용을 지원](https://ai.google.dev/gemini-api/docs/pricing)하지만 실제 한도와 과금은 해당 Google 프로젝트의 결제 설정을 따른다.

자동 검사 `npm test`는 **339/339**, TypeScript 검사와 프로덕션 빌드도 통과했다. 실제 API 시나리오는 인사·일반 지식·현재 날씨·지역 재질문·RAG 당일 생성·3일 생성·당일로 재생성·기존 DAY 조회·예약을 보존하는 일부 교체·Gemini 자동 전환 **10종 모두 통과**했다. 최종 합산은 각 최신 재검증과 변경 영향 없는 기존 결과의 원본 파일·해시를 함께 기록한다. 최초 실패와 이전 로컬 14B 검증도 보존했다.

실행 기록은 `work/handoff/CHATBOT_MATRIX_20261016_FINAL.json`, 최신 제외 조건 검증은 `CHATBOT_MATRIX_20261016_LIVE_3_FLAGS.json`, 브라우저 검증 기록은 `CHAT_ANCHOR_QA_20261016.json`에 있다. 브라우저의 네트워크 실패는 별도 로컬 QA 주소에서 재현했고, 원래 앱 서버를 중단하지 않고 재시도를 확인했다. 마지막 브라우저 검사에서는 오류 배너 제거 후 대기 중인 사용자 글이 메뉴 아래 **15.953px**에 정렬되었다. 모델을 추가 호출하지 않는 기존 DAY 조회를 검증용 프록시에서 12초 지연하고 이전 글로 수동 스크롤한 뒤, 답변 완료 때도 그 읽기 위치가 유지되는 것을 확인했다. ‘최근 대화’ 버튼은 다시 **15.953px**에 정렬했고, 출처를 펼쳐도 스크롤 위치가 유지되며 공식 링크 12개가 보였다. DAY 1·2 카드는 브라우저에서 확인했고, DAY 3 개별 탭 전환은 UI 도구 시간 초과로 확인하지 못했다. 3일 전체 방문 데이터는 실제 API 검증을 통과했다.

검증용 프록시와 QA 탭은 종료했고 원래 앱 주소는 HTTP 200으로 남아 있다. 실패 질문은 현재 화면의 메모리 상태이므로 전체 페이지를 새로 열면 성공한 대화 기록만 복원된다.
