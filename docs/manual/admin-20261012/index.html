메뉴 선택 기준

1. 운영 현황오늘 할 일을 시작하고, 담당 자료의 미완료 작업을 이어가는 곳
지역·담당 범위 선택 → 등록 / 검수 / 추천 여행 만들기
2. 장소·업체지역과 랜드마크·음식점·카페·숙소의 원본 자료를 관리하는 곳
지역 설정 → 장소 등록 → 위치·사진·출처 확인 → 공개
3. 노출·추천추천 여행을 만들고, 인기 장소·여행기를 골라 홈에 게시하는 곳
추천 여행 만들기 / 인기 콘텐츠 선택 → 게시 위치·기간·순서 지정
4. 여행기·커뮤니티공개 여행기·댓글·답글·신고와 번역을 확인하는 곳
대상과 문맥 확인 → 사유 입력 → 해당 대상에 조치
5. 회원·문의회원의 공개 프로필·상태·계정 요청과 문의를 처리하는 곳
회원 또는 문의 검색 → 담당자·처리 상태 확인 → 조치 기록
6. AI·검색 운영장소 설명의 검색 반영, 추천 품질, 실패 원인과 실행 기준을 관리하는 곳
검색 자료 → 색인 작업 → 품질 시험 → 요청 현황 / 실행 정책
7. 운영 설정·이력분류·등급·운영자·알림·연결·휴지통·변경 기록을 관리하는 곳
바꾸려는 운영 기준의 탭 선택 → 저장 → 변경 이력 확인

초안 · 공개 · 메인 게시의 차이

초안 저장

작성 중인 내용 보관. 장소는 기존 공개본 유지. 추천 여행의 초안 저장은 해당 여행을 비공개로 전환하므로 별도 확인.

검수하고 공개

확인한 자료를 공개본으로 적용. 새 홈 게시 위치는 ‘메인 게시 관리’에서 지정.

메인 게시 저장

대상·채널·순서·기간·켜짐 설정. 해당 채널의 게시 조건에 따라 노출.

이미 게시 중인 대상이나 연결된 홈 추천 원본을 수정·공개하면 기존 게시 내용도 갱신될 수 있음. 새 게시와 기존 콘텐츠 갱신을 구분.

캡처는 별도 환경의 예시 자료로 진행. 실제 회원 조치·AI 호출·알림 발송·파일 정리는 서버 연결 필요. 화면의 사용법과 실제 처리 완료는 구분해서 확인.

헷갈리기 쉬운 기준

지역과 장소
지역 추가·수정은 ‘장소·업체 → 지역 설정’. 업체는 실제 지점 단위로 등록. 같은 상호라도 주소와 좌표가 다르면 별도 장소.
공개 상태와 영업 상태
공개는 고객에게 사용할 자료인지에 대한 설정. 영업 중·임시휴업·폐업은 현재 운영 상태. 서로 다른 항목으로 관리.
주변 후보와 운영자 추천
좌표로 조회한 거리 후보와 직접 선정한 추천을 구분. 기본 직선 3km, 필요하면 15km로 확장. 이동 시간과는 다름.
사진 출처와 사용 범위
사진마다 원문·제공자·사용 조건 확인. 출처 표기가 사용 허가를 대신하지 않음. 확인한 범위만 표시·보관·AI 활용에 적용.
검색 자료 · 색인 · 정책
검색 자료는 승인된 장소 설명. 색인은 그 설명을 찾는 검색 목록의 버전. 정책은 모델·기능·시간·비용 제한 등 AI 실행 기준.
버튼이 비활성화된 경우
필수 정보·사용 범위·권한·처리 중 상태 확인. ‘공개 전 확인 항목’에서 누락된 입력으로 이동해 해결.
동시에 수정했다는 안내
입력 내용을 먼저 확인하고 최신본과 비교. 최신본 다시 읽기는 현재 입력을 바꿀 수 있으므로 무작정 반복 저장하지 않기.
휴지통과 신고 숨김
사용자 휴지통은 한국 시각 기준 달력 6개월. 복원은 비공개. 신고 숨김과 별도 상태이며, 사진은 다른 기록의 사용 여부도 확인.
관리자가 보는 고객 자료
공개 프로필·공개 여행기·대상 댓글·요청 처리 중심. 개인 일정·메모·AI 요청문·대화 원문은 기본 열람 대상에서 제외.
식별자와 연결
placeId는 개별 장소, mediaId는 사진·영상, journalId는 여행기. 화면의 제목이 같아도 실제 ID를 확인해 대상 구분.
화면이 바뀌면 같은 경로의 최신 캡처와 설명을 함께 갱신. 본 매뉴얼은 현재 관리자 사용법 안내.
