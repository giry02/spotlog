# 2026-10-26 챗봇 전체 점검과 클릭 편의성 보강

모아 챗봇의 현재 소스를 점검하고 발견한 오류를 수정했습니다. 업로드 대상은 `giry02/spotlog`의 챗봇 전용 `codex/moa-demo` 브랜치입니다. Spotlog 앱 본체와 공개 Sites 배포는 이번 변경 범위에 포함하지 않습니다.

## 수정한 오류

- **와이파이 HTTP에서 요청/댓글 ID 생성 실패**: 안전한 컨텍스트에서만 제공하는 `crypto.randomUUID()`에 직접 의존하던 브라우저 코드를 공통 함수로 교체했습니다. 일반 HTTP에서는 암호학적 `getRandomValues()`로 같은 UUIDv4를 생성합니다. 대화·시나리오·초기화·스레드·앱 연결에 동일하게 적용하고 보안용 nonce를 약한 난수로 대체하지 않습니다.
- **기존 여러 박 숙박의 DAY 복사 경계**: 복사한 숙박의 체크아웃이 늘어난 여행 기간을 넘으면 DAY 복사를 전체 거절합니다. 직접 조작과 LLM 계약에 같은 검사를 적용하고, 기존 정상 일정·원본 저장본·예약 조건은 보존합니다.
- **다른 DAY에 업체 추가 시 이전 장소를 기준으로 조회**: 명시적으로 다른 DAY에서 식당·카페·숙소를 찾으면 해당 DAY의 장소를 검색 기준으로 잡습니다. 같은 DAY에서는 직접 선택했던 기준 장소를 유지합니다.

## 클릭으로 등록하고 확인

- 일정에서 **식당 추가하기 · 카페 추가하기 · 상점 추가하기**로 후보를 찾고, 선택 후 표시된 DAY에 추가합니다.
- 장소·업체·숙소를 둘러보는 동안 **DAY n 일정으로 돌아가기**로 후보를 고르지 않고 돌아갈 수 있습니다.
- 저장 후 **저장한 여행 확인**으로 보관함을 열 수 있습니다. 저장본 방문 수와 현재 내용의 저장 여부를 구분해 표시합니다.
- 스레드 상단 **글 쓰기**로 입력창에 이동합니다. **내 글 확인**은 최근 내 글·답글을, 등록/수정 후 **등록한 글 보기 · 수정한 글 보기**는 정확히 해당 글을 찾아 강조합니다. 글을 다시 등록하거나 새 대화를 만들지 않습니다.
- 샘플 타인 글은 수정·삭제할 수 없고 내 글만 관리합니다. 샘플·기기 기록·실제 회원 서버 미연결 상태는 구분합니다.

## 검수 범위

- 자동 테스트 **804개 통과**, TypeScript 검사, production 빌드.
- 공개 코스 11개에 대한 가져오기 → DAY/방문 수정 → 저장 → 초기화 → 재열기 → 전체 지도 생성 **270개 경로** 검사.
- 실제 390×844 모바일 화면에서 작성자 소개, 식당·카페·숙소 상세 펼치기/접기, 코스 상세 위 스레드 팝업과 Escape 복귀 확인.
- 제주 11곳 전체 지도 **11개 지점·10개 구간**, DAY 2의 전날 숙소 출발 포함 확인. 지도는 화면 안에 들어오면 불러옵니다.
- 제주 코스 가져오기 → 제목·날짜·방문 시간·메모 수정 → DAY 2 카페 버튼 → 거리 확대 → 후보 선택·추가 → **12개 방문 저장** → 저장본 확인.
- 실제 와이파이 HTTP 주소에서 대화 실행, 글 등록·수정, 샘플 원글 답글, 등록/수정한 글 찾기, 내 글 바로가기, 초기화 확인.
- 실제 LLM에 **협재신국수 스레드 보여줘** 요청 → **큰 모델 응답**으로 같은 패널 표시 → 버튼으로 글 등록·확인.

실제 서비스의 모든 자연어 표현·모든 기기·모든 외부 API 장애를 검증한 것은 아닙니다. 도로 경로를 확인하지 못하면 전체 위치의 직선 연결을 명시하고, 실제 회원 게시·평가 서버·예약·결제는 연결 전 상태를 유지합니다.
