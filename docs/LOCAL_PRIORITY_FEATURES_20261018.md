## 검증과 재현

자동 검사는 `node --require ./scripts/local-hidden-children.cjs --test tests/*.test.mjs`, 타입 검사는 `node --require ./scripts/local-hidden-children.cjs ./node_modules/typescript/bin/tsc --noEmit`, 빌드는 동일 숨김 자식 프로세스 프리로드로 Vinext build를 사용한다. 숨김 런처를 우회해 새 콘솔 서버를 띄우지 않는다.

최종 코드 기준 **전체 550개 검사 통과·실패 0**, TypeScript 검사와 프로덕션 빌드 성공을 확인했다. 실제 앱 iframe 21개 검사는 별도 브라우저 검수다.

실제 브라우저 검수는 사용자 원래 localhost 탭을 건드리지 않고 별도 `[::1]:3001`의 합성 QA 대화에서 수행했다. 실제 앱-챗봇 iframe 검수는 격리된 브라우저 저장소로 수행했다. 운영 데이터나 사용자 원본 여행을 수정한 증거가 아니다.

1. 실제 LLM으로 부산 해운대해수욕장·동백섬·광안리해수욕장 2일 일정 생성.
2. LLM으로 여행명·2026-11-03 출발일·10:30 방문·90분 체류·메모 수정 후 나머지 방문 보존 확인.
3. 실제 등록 식당과 숙소 조회. 미확인 가격·영업·빈방 및 원문/사진 이용 조건 확인.
4. 점심 후보 보관→라디오 선택→확정. 원래 점심 순서에 한 식당만 반영하며 과거 카드 라디오와 충돌하지 않음.
5. 등록 숙소 선택만으로 일정 불변→체크인 DAY·1박 적용. 새 DAY 추가 후 2박 적용과 전날 숙소 출발 연결.
6. 전체 지도에 관광지·식당·숙소 5개 확인 지점 표시. 모바일 390px 가로 넘침 없음. 도로 경로 공급 및 미정 방문 제외 표시 확인.
7. 바텀시트 상세 열기가 대화 수를 늘리지 않음. 저장→휴지통→6개월 기한→복원→열기 및 새로고침 후 날짜·메모·연박 보존.
8. 실제 API에서 신규 메모리 세션으로 **식당 2곳만 담기→관광지 없이 당일 생성**, **국제시장→자갈치시장 두 상점만 담기→당일 생성** 각각 실제 모델 2회 왕복 성공. 상점 최초 실패는 원인을 수정한 후 동일 원문으로 재검증했다.
9. 실제 5210 앱+3001 챗봇 iframe에서 320/390/460px **21개 검사 통과**. 두 DAY 전체·원래 번호 DAY 2만·선택한 찜 한 곳만 읽기, 취소 시 미전달, 약관 이동 후 복귀 확인. 양쪽 저장소 전후 동일.

증거는 `work/audit-20261018/priority-tests-final.log`, `priority-build-final.log`, `work/handoff/priority-ui-20261018/`, `work/handoff/priority-real-llm-20261018/`, `work/handoff/chatbot-real-iframe-20261018/results.json`에 있다. `CATALOG_PRIORITY_20261018.md`, `UI_PRIORITY_REVIEW_20261018.md`, `QUIET_STACK_RECOVERY_20261018.json`도 함께 참조한다. 실제 검증 완료 시점의 전체 테스트 수는 최종 로그를 따른다.

## 이어받을 때

먼저 이 문서와 최종 검사 로그를 확인한다. 같은 폴더에 이미 적용된 변경이므로 전체 파일 덮어쓰기·초기화·과거 프로토타입 복사를 하지 않는다. 무료 우선 모델 정책·키·로컬 데이터·사용자 대화·기존 예약 보호를 유지한다. 다음 서비스 단계는 공통 회원/여행 DTO와 원본 저장 권한·충돌 처리, 외부 검색 공급 계약·어댑터, RN 실제 브리지·OS 권한을 구체화하는 일이다. 사용자가 이번 변경을 로컬에만 두라고 했으므로 추가 지시 전에는 공개하지 않는다.
