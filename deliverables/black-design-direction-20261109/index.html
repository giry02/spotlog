유지

보강

추천 안의 여행 콘텐츠

기존 정모·모임·장소를 지우지 않고 여행 코스와 공개 여행기를 함께 노출합니다. 여행이 항상 먼저여야 한다는 안은 아닙니다.

연결

개인과 그룹의 활용

장소를 저장하고 코스를 내 여행으로 가져오거나 가족·친구·취미 모임과 나눕니다. 일상 만남과 커뮤니티도 유지합니다.

01 · 지금 디자인의 평가

차분함은 장점.
모든 항목이 비슷한 무게인 건 약점.

깨진 화면을 제외해도 개선할 이유가 있습니다. 아래는 현재 소스와 대표 캡처에 대한 디자인 판단이며, 소모임 공개 웹의 특정 상태는 같은 너비에서 직접 비교했고, 이를 전체 네이티브 앱 규격으로 일반화하지 않았습니다.

  • 폰트는 이미 정보형에 가깝습니다.

    현행 여행 행은 제목 16/22, 설명 14/20, 메타 12/16px입니다. 문제를 ‘전부 크다’로 진단하면 가독성을 희생할 수 있습니다.

  • 두꺼운 제목과 잦은 선이 주목도를 나눕니다.

    작은 도구와 큰 섹션이 비슷하게 강조되고 선이 반복됩니다. 중요한 이름·다음 일정만 선명하게, 설명과 도구는 한 단계 낮춥니다.

  • 여백을 줄일 곳과 남길 곳이 다릅니다.

    중복 상단·조건·상태 줄은 모으고, 서로 다른 정보 구역 사이에는 쉬는 간격을 둡니다. 같은 그룹 안 여백과 섹션 사이 여백을 구분합니다.

  • 검정은 유지하되 역할을 제한합니다.

    탭은 밑줄, 조건은 가벼운 선택 표시, 대표 실행은 검정 채움으로 나눕니다. 반복 가입 버튼까지 전부 검정으로 칠하지 않습니다.

02 · 4개 화면 예시

주요 정보와 대표 행동을
분명하게.

기존 검수 화면과 제안은 같은 데이터의 전후 결과가 아닙니다. 기존 화면은 격리 검수 데이터, 제안은 구성을 보여주기 위한 예시입니다. 사용자의 정정에 따라 상단 탭과 혼합 추천을 로컬에 복원하고 UI로 확인했습니다. 아래 모임 찾기·대화·여행 상세는 여전히 제안이며 전체 적용 완료가 아닙니다.

이미지를 누르면 확대합니다. AI·위치·추천 수치는 제안 화면의 서비스 연동을 증명하지 않습니다.예시 HTML 열기 ↗
로컬 복원 · UI 확인

기존 상단 탭과 혼합 추천을 유지해 여행을 보강했습니다.

상단 추천 / 번개·정모 / 모임 / 장소 찾기 / 여행 탭을 유지했습니다. 추천에는 번개·정모 2개→모임 3개→여행 코스 2개→여행기 2개→장소 4개가 함께 이어집니다. 아래 세 번째 이미지는 여행 구역까지 스크롤한 별도 상태이며 첫 화면이 아닙니다.

실제 로컬 UI의 대표 상태 확인입니다. 모임 찾기·대화·여행 상세 3개 목업의 전면 적용, 서버·실시간·실제 AI 완료를 의미하지 않습니다. 이번 복원 기준 전체 웹 테스트 1,087개·실패 0, 핵심 검증 101개, web:typecheck·web:build·오프라인 11개 파일 검증을 통과했습니다. 320·390·460px와 각 상단 탭·단일 검색·빈 결과·상세 복귀도 확인했습니다. Git 업로드·배포는 하지 않았습니다.

대화 예시의 AI는 목표 경험입니다. 현행 일반 대화는 키워드별 원문 모아보기이며, 구조화된 AI 정리는 지정 가상 대화 예시입니다. 실제 LLM 연결·정확도 검증·사람의 반영 확인을 거쳐야 제공합니다.

03 · 플랫폼의 중심을 다시 정의

기존 발견 구조를 유지하며,
여행 콘텐츠의 빈칸을 채웁니다.

사용자 정정에 따라 탭 제거와 여행 전용 기본 홈 제안을 철회합니다. 모임·정모·장소·여행을 추천에서 함께 보고, 기존 상단 탭으로 범주별 탐색을 이어갑니다.

추천은 모임·장소·여행을 함께 보여주고,
각 상단 탭은 해당 범주를 더 찾아보게 합니다.

무엇을 누르면 어떻게 이어지나

이번 정정의 범위 · 탭 제거·여행 전용 홈을 철회하고 기존 상단 탭과 혼합 추천을 로컬에 복원해 UI로 확인했습니다. 실제 이미지와 전체 웹 1,087개·타입·빌드·오프라인 검증 결과 모두 이번 복원 이후 최신 증거입니다.

이 방향을 검증할 두 가지 사용 여정

현재 강점과 검증 전 가설을 구분합니다. 코스 복사·장소 저장·모임별 협업의 기반은 있습니다. 차별화 후보는 경험 발견→내 일정 재사용→필요한 모임과 실행→다음 콘텐츠 공유의 연결 편의입니다. 모든 콘텐츠의 통합 공유, 재방문 효과, 실시간 공동 사용, AI 품질을 이미 완성했다고 주장하지 않습니다.

04 · 추가 반영할 4가지

우선 완성할 것은
기존 기능 사이의 연결입니다.

상단 탭·혼합 추천 유지 → 여행 보강 → 활용 연결 → 실제 공동 사용·AI 검증 순서입니다. 도구가 많아지는 것 자체를 목표로 삼지 않습니다.

AI 추가 아이디어는 ‘짧은 브리핑’부터

첫 참여 브리핑
공식 공지에 있는 합류 장소·회비·준비물을 한 장으로. 없는 정보는 확인 필요로 남깁니다.
지난 코스에서 다음 초안
본인이 고른 장소·후기만 새 초안에 재사용합니다. 참석·예약은 새로 확인합니다.

미래 제안입니다. 일부 수동 도구와 재사용 구조가 있어도 이 세 가지를 실제 AI로 제공한다는 뜻은 아닙니다.

05 · 국내외 벤치마킹

벤치마킹에서 가져올
명확한 탐색과 실행 구조.

국내 3곳·해외 4곳의 공식 공개 자료를 확인했습니다. 소모임의 17장 제공 이미지와 11월 8일 직접 관찰도 구분해 참고했습니다. 소모임 공개 추천 웹의 대표 상태는 직접 실측했으며, 다른 앱의 폰트·간격·색상 규격까지 측정한 조사는 아닙니다.

서비스확인한 장점우리에게 적용그대로 가져오지 않을 점공식 근거
공개 웹 화면 참고 이미지 3개

공식 공개 웹을 확인한 참고 이미지입니다. 모바일 네이티브 앱 전체나 정확한 UI 치수의 근거는 아닙니다. 제안 화면의 데이터·디자인으로 복제하지 않았습니다.
