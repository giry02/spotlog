화면별 변경

  • 홈: 지역·검색·메뉴를 한 줄로 통합. 입력 중에는 지역을 접어 검색 폭을 확보하며 검색 조건을 지우지 않습니다. 추천·만남·모임·장소·여행을 유지합니다.
  • 모임 찾기: 지역·동네·관심사·날짜는 요약 한 줄과 펼침 조건으로 구성. 검색·정렬·지속 모임/개별 만남 전환을 유지합니다.
  • 내 모임: 가족·친구·취미·가이드 분류는 한 줄 스크롤. 초대·할 일은 정렬 옆에서 바로 엽니다.
  • 관심 장소: 목록·지역·종류·검색을 교차 적용. 행을 누르면 사진·상세를 보고 담기/이동/해제/관리는 목록에서 실행합니다. 저장 취소는 상세에서 처리하고 다음 행으로 포커스를 돌려줍니다.
  • 대화: 정리는 헤더, 실행 도구는 입력창 +, 기존 공지·투표·준비는 통합 상태줄에서 조회합니다. 방 메뉴에서 같은 모임/약속 안의 화면으로 이동합니다.
  • 생성·여행기·프로필: 진행 단계와 하단 행동을 축약하고 헤더 가림을 보완. 작은 주요 버튼은 44px로 확대하고 계정 카드의 반복 여백을 줄였습니다.

15개 주요 화면을 320/390/460px로 검수하고 역할·프로필·짧은 화면을 더해 총 59개 화면 조합을 확인했습니다. 최종 화면에서 페이지 가로 넘침·내용 영역 가로 넘침·깨진 이미지는 발견하지 않았고 해당 검수 탭의 경고/오류 로그는 비어 있습니다.

  • 320px에서도 검색 입력 중 150px 폭을 확보하고 지우기 버튼을 유지합니다.
  • 추천 검색 결과가 없으면 한 개의 빈 상태를 표시하며 초기화 시 지역·검색어를 함께 지웁니다.
  • 여행 탭에 내 여행·여행 만들기·여행기 진입이 남아 있습니다.
  • 부산·카페·7일 조건을 선택하고 개별 만남으로 전환해도 조건이 유지됩니다.
  • 관심 장소의 폴더·지역·숙소·이름 검색을 교차 적용해 한 호텔을 찾습니다.
  • 음식점·호텔의 상세 사진·주소·설명이 정상으로 나옵니다.
  • 저장 취소 후 다음 장소 행으로 키보드 포커스가 돌아옵니다.
  • DAY 1 담기→DAY 2 이동 시 표시와 실제 담긴 개수가 일치합니다.
  • 생성 단계 이동 후 질문이 상단 헤더에 가리지 않으며 입력 글자 16px를 유지합니다.
  • 최신 대화로 이동한 뒤에도 공지와 새 투표를 통합 상태줄에서 찾습니다.
  • 채팅 검색의 빈 결과·원문 이동과 같은 약속 안의 준비 화면 이동을 확인했습니다.
실제 휴대폰 키보드·시스템 글자 확대·보조기기 검수는 별도입니다. 기존 사진 출처의 작은 보조 행동은 유지했습니다. 실제 서버·로그인 공급자·실시간 대화·LLM 연결을 완료한 작업은 아닙니다. 빌드의 기존 대용량 청크 안내는 남아 있습니다.

다음 개선 후보

  • 모임 홈은 신규 가입자에게 소개·가입 안내, 기존 멤버에게 다음 약속·새 대화를 우선하는 구성을 실제 이용으로 비교합니다.
  • 준비·게시판·앨범의 긴 목록에 검색과 최근 확인 위치를 함께 제공하는 방안을 검토합니다. 메뉴를 더 늘리기보다 해당 공간 안의 탐색을 우선합니다.
  • 실기기에서 한 손 조작·긴 입력·키보드·시스템 큰 글자를 확인하고, 홈의 많은 목록과 지도는 필요할 때 불러오도록 성능을 분리 점검합니다.
