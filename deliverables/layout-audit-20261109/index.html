국소적인 깨짐을 고친 뒤, 정보 배치와 시각 규칙을 맞춥니다.

01

03

버튼 역할과 색상의 모호함

탐색 탭·조건 칩·실행 버튼을 검정 채움과 흰 윤곽만으로 구분합니다.

04

여행기 하단의 실제 깨짐

버튼 하나가 예전 86px 칸에 갇혀 여러 줄로 접히고 오른쪽이 비어 있습니다.

유지할 것장소·저장의 64~72px 사진과 짧은 행, 14px 본문, 44px 터치, 기존 코랄 브랜드, 모임·일정의 권한과 자료 범위.

벤치마크에서 가져올 것은 역할입니다

소모임처럼 복제하는 대신, 우리 플랫폼의 목적에 맞게 해석합니다.

근거의 범위 · 사용자가 제공한 소모임 화면 17장과 2026-11-08 당근 앱 직접 관찰 기록을 참고했습니다. 이번 검수에서 당근을 새로 직접 탐색한 것은 아닙니다. 타 서비스의 픽셀·폰트 수치를 실측했다고 주장하지 않습니다.
관찰한 구조장점Spotlog에 적용할 방향
소모임 목록작은 사진 + 제목 + 짧은 소개 + 지역·인원으로 여러 후보를 비교합니다.장소·저장의 현재 목록 밀도는 유지합니다. 모임에서는 이름 공간과 빠른 가입 버튼의 폭을 다시 나눕니다.
소모임 탐색 계층상단 화면 탭, 관심사 분류, 모임 내부 탭의 역할이 구분됩니다.하단 목적지·상단 탭·조건 칩을 다른 모양과 위치로 구분합니다. 선택을 마치면 조건을 요약해 결과를 먼저 보여줍니다.
소모임 사진첩·클래스사진 감상과 정보 비교에 서로 다른 배치를 사용합니다.앨범은 사진 중심 그리드, 장소는 정보 행, 여행 추천은 대표 콘텐츠와 짧은 목록으로 구분합니다.
당근 지역·세부 분류활성 동네와 대분류 아래의 세부 관심사가 보이고 정렬·추가 조건이 분리됩니다.선택 지역을 명확히 표시하고 선택 후 상단을 압축합니다. 실제 GPS·반경 기능이 있는 것처럼 표현하지 않습니다.
당근 모임 생성·운영소개 초안 확인과 최종 생성, 가입 정보, 모임 안의 도구를 단계로 나눕니다.폼의 필수·선택·확인을 구분하고 채팅 도구는 모임·일정의 정확한 범위 안에서 제공합니다. 기존 승인·바로 가입은 유지합니다.
