    가입한 모임의 홈으로 이동. 약속이 없어도 전체 대화와 장소 제안에 접근.

    개인 저장·초안을 그대로 이어가기. 모임 가입이나 공유를 선행 조건으로 요구하지 않기.

가입 전에 어떤 사람·활동이 있는지 판단

  1. ① 지역·관심사

    설정한 지역에서 공개 자료 탐색. 현재 위치 권한은 위치 기능을 쓸 때 별도 요청.

  2. ② 공개 안내

    모임 소개·다음 약속·가입 조건을 먼저 열기. 열람만으로 가입 신청하지 않기.

  3. ③ 서로 다른 목적

    모임과 장소를 한 종류의 카드처럼 섞지 않기. 누르면 선택한 발견 목록으로 이동.

  4. 개인만 쓰는 회원

    저장·일정이 있으면 개인 이어하기를 함께 제공. 모임 만들기 안내를 계속 반복하지 않기.

지역과 관심사를 기준으로 새로운 관계·장소 발견

  1. ① 공통 조건

  2. ② 모임 카드

    이름·지역·관심사·모집 상태·선정된 다음 공개 약속으로 가입 판단 돕기. 순위·활성 숫자는 실제 집계가 있을 때만.

    같은 모임 발견 영역에서 약속 목록으로 전환. 날짜·시간·소속 모임을 우선 표시.

  4. 복귀

    공개 상세를 보고 돌아와도 지역·관심사·검색어·스크롤 유지. 결과가 없으면 조건 완화 행동 하나 제공.

모임의 성격과 첫 참여 조건 확인

  1. ① 소개

    외부인이 읽을 공개 소개. 가족·초대 전용 모임은 공개 탐색에서 제외.

    선정된 공개 약속만 표시. 비공개 장소·내부 대화·사진을 가입 유도용으로 노출하지 않기.

  3. ③ 신청

  4. 승인 후

    먼저 선택했던 유효한 약속으로 복귀. 가입 승인과 정모 참석을 각각 처리.

소개보다 다음 만남과 함께 정할 일을 먼저

  1. ① 공지

    제목 한 줄로 먼저 표시. 전체 내용은 같은 모임에서 열고 닫기.

    모임의 예정 약속 표시. 내 참석 약속과 참여 전 일정을 상태로 구분.

    관심 장소에서 가져온 공개 장소 정보로 의견·투표 진행. 선택 후 권한자가 약속 초안 생성.

  5. ⑤ 기록·운영

    지난 약속별 사진·후기·다음 만남 연결. 초대·멤버·공개 모집·관리 도구는 더보기에 배치.

일시·장소·참석·준비를 한 맥락에서 확인

  1. ① 일시·장소

    첫 화면에서 핵심 사실 확인. 미정·예약 여부는 현재 상태 그대로 표시.

  2. ② 참석

    회원이 직접 참석 선택. 모임에 가입됐다고 참석이나 예약을 자동 확정하지 않기.

  3. ③ 개별 대화

    같은 약속 안에서 열기. 기존 모임원 열람 정책은 유지하고 참석자 전용으로 새로 제한하지 않기.

  4. ④ 준비

    담당·완료·미정을 구분한 체크리스트. 일정과 원문 근거로 연결.

  5. ⑤ 활동 유형

개인의 장소·일정·기록을 한곳에서 관리

  1. ① 1회 접근

    하단 내 공간의 기본 진입은 저장 장소. 계정·설정으로 채우지 않기. 상세 복귀는 원래 목록 조건·위치 유지.

  2. ② 다음 행동

    선택하기 전에는 관리·생성 버튼을 크게 쌓지 않기. 장소 선택 후 내 일정 담기 / 모임 제안 제공.

  3. ③ 보존

    개인 일정·여행기·메모 원본은 개인 소유로 유지. 모임 공유·해제·복사 상태를 구분.

  4. 이동 비용

    기존 내 여행 하단 직접 진입보다 개인 일정은 한 번 더 선택. 홈의 작성 중 일정 이어가기와 모임의 약속 직접 진입으로 보완.

모임장의 첫 화면

같은 홈 틀에서 처리할 신청이 있으면 작은 우선 행을 추가. 다음 약속·공지·가입 검토 중 지금 필요한 행동 하나를 먼저. 홈 전체를 관리 화면으로 바꾸지 않기. 제품에 역할 전환 버튼을 넣는 안은 아님.

05

무엇을 누르면 어떻게 이어지는가

가입·초대·장소 제안·정리·기록을 별개의 목록에서 끝내지 않고 다음 단계로 연결.

01

처음 발견 → 첫 약속

둘러보기 → 공개 모임·약속 → 가입 신청 → 승인 → 선택했던 약속 → 참석 선택

가입 전 열람은 공개 선정 정보만. 승인과 참석 분리. 약속 취소·공개 철회 시 대체 안내.

02

개인 장소 → 함께 결정

관심 장소 선택 → 모임에 제안 → 의견·투표 → 권한자가 약속 초안 → 일정 확인 후 공개 범위 선택

개인 메모·방문 이력은 제안에서 제외. 투표 결과만으로 참석·예약을 확정하지 않기.

03

개인 일정 → 초대로 모임 시작

개인 일정·여행기 선택 → 공유 범위 확인 → 카카오 초대 링크 → 상대 수락 → 모임 생성

첫 유효 수락에서 한 모임 생성. 보낸 사람이 모임장. 추가 수락은 같은 모임 가입. 개인 원본은 유지.

04

긴 대화 → 해야 할 일

대화 정리 → 결정·변경·미정·준비 구분 → 원문 확인 → 선택 → 준비 / 공지·투표 초안

발언자·기간·방 범위를 유지. 원문 수정·삭제·권한 변경 시 재검증. 사용자 승인 없이 자동 적용하지 않기.

05

지난 활동 → 다음 만남

지난 약속 → 사진·후기 → 같은 모임의 다음 약속 → 참석 또는 다음 만남 제안

공개 후기와 내부 기록 분리. 일정이 없으면 빈 화면 대신 장소·시간 제안으로 연결.

06

모임장 → 모집·운영

가입 대기 확인 → 승인·거절 → 모집 소개·공개 약속 선정 → 미리보기 → 홈·발견 노출

모집 공개와 내부 전체 공개 분리. 실제 인기·운영자 추천 표기 구분. 임의 가입·참석 숫자 입력 제외.

07

휴대폰 → PC에서 이어쓰기

같은 계정 → 같은 모임·약속 선택 → 대화·준비·기록 확인 → 명시 저장

계정·권한·최신 버전을 서버로 맞추는 후속 연결 필요. 현재 로컬 저장만으로 기기 동기화가 된 것으로 표시하지 않기.

06

AI는 대화에서 실행할 일을 찾는 도구

전체·안 읽은 대화·특정 사람·기간으로 범위 선택. 검색·정리 결과는 근거와 함께 보고 필요한 항목만 반영.
