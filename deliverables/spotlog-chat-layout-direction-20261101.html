현재 메뉴제안하는 첫 화면뒤로 보내는 기능
홈내 다음 약속·이어할 일 → 지역별 발견긴 소개·중복 추천·생성 안내
둘러보기지역 선택 → 장소 / 모임 / 기록 중 대상 선택 → 결과조건이 다른 목록을 한 피드에 섞어 노출
함께하기 → 모임다음 약속·새 대화 → 내 모임 목록. 별도 ‘모임 찾기’ 진입모임 소개·관리 도구·긴 배너
내 여행내 일정과 여행기 구분 → 작성 중·예정·지난 기록공개 여행기 탐색·중복 작성 유도
관심 장소저장 목록 → 지역·종류 필터 → 목록 / 지도큰 여행 만들기 카드. 선택 후 작은 실행 버튼으로 제공

메뉴 명칭은 방향 제안. 지금 제품의 하단 메뉴와 화면 구조를 일괄 변경한 상태는 아님.

공통 레이아웃 기준

한 화면, 주 행동 하나

저장·가입·참석·작성 중 하나가 먼저 보이게. 보조 작업은 더보기로 묶기.

필터는 한곳에

지역 → 종류 → 결과 순서 통일. 가로 버튼 줄 중첩과 중복 탭 축소.

확인은 같은 공간에서

일정·준비·AI는 패널로 확인. 상세에서 나와도 필터·스크롤·초안 유지.

본문·입력 16px 이상, 버튼 44px 이상 목표. 한 화면 안에 세로 스크롤 영역을 여러 개 중첩하지 않기. 공통 페이지 헤더·탭·카드 간격 통일.

개편 순서　모임·약속·대화의 이동 구조 → 홈·둘러보기의 정보 구분 → 관심 장소·내 일정의 작업 흐름 → 모바일·PC 공통 규칙 적용.
검수 기준　처음 보는 사람이 어디를 눌러야 할지 알 수 있는지, 같은 맥락에서 뒤로 가기 없이 확인 가능한지, 복귀해도 하던 일이 남는지.

구체적인 배치 예시 · 모임 대화

현재 불편의 원인

대화 위에 헤더·요약·안 읽은 대화·공지가 따로 쌓임. 관찰한 기존 화면에서 이 네 블록의 높이만 약238px. 도구가 본문과 함께 스크롤되어 다시 찾기 어려움.

권고하는 5가지 변경

  1. 01

    헤더 + 공지 한 줄만 고정

    상단은 약108px 목표. 큰 요약·미독 카드 제거. 공지 제목은 한 줄, 전체 내용은 눌러 열기.

  2. 02

    AI·검색은 항상 같은 위치

    AI 아이콘을 누르면 결정·미정·준비·담당자 정리. 안 읽은 수는 공지 줄의 작은 버튼으로 유지.

  3. 03

    방은 제목을 눌러 전환

    모임 전체방과 그 안의 개별 약속방을 한 목록에서 이동. 전역 채팅 탭은 추가하지 않기.

  4. 04

    확인은 패널, 이동은 최소

    메뉴의 일정·준비·사진을 같은 방의 패널로 열기. 근거를 누르면 대화 강조, 그때만 정리 복귀 버튼 표시.

  5. 05

    입력창과 아래 화살표 위치 고정

    대화 영역만 스크롤. 최신 대화로 가기는 우측 아래 화살표. 답장·반응은 아이콘과 접근성 이름 제공.

AI 예시에서 확인할 것
10시·1번 출구 제안 → 10시30분·2번 출구로 변경. 식당 투표·예약 문의는 완료와 구분. 엄마·지우의 준비물은 해당 발언 근거로만 정리.

앱 전체에도 같은 원칙 적용

홈내가 이어할 일과 지역 탐색이 먼저. 안내·생성 카드 중복 축소.
발견지역 → 대상·종류 → 결과. 상세와 복귀에서 조건 유지.
모임다음 약속이 먼저. 소개·멤버·관리 도구는 메뉴로 묶기.
약속일시·장소·참석을 기본. 준비·대화·기록은 같은 공간에서 접근.
