## 화면별 밀도·원터치 판단

- **홈**: 장소/모임/여행 역할 탭, 수동 카드, 탭·지역·뒤로 복원 구조는 적절. 비슷한 내용을 한 홈에 계속 추가하는 방향보다 현재 분리 유지. 기존 장소 저장은 카드에서 한 번 조작.
- **관심 장소**: 지역·종류를 항상 보이고 저장 카드가 먼저 나오는 현재 기준 유지. 추가 편의는 접이 검색 한 가지로 제한하는 편이 나음. 새 여행 버튼을 다시 큰 상단 영역으로 확장할 필요 없음.
- **내 여행 작성**: 메인 버튼을 이미 완료 하나로 줄였음. 현재 남은 문제는 작은 보조 버튼과 장소 상세 편집 패널의 희귀 조작 나열. ‘메모/시각/체류’와 ‘이동/복사/연결해제/삭제’를 단계적으로 나누되 기능 삭제 없이 고급 조작만 접을 수 있음.
- **공개 모임 탐색**: 관심사 8개+더보기, 지역/동네, 날짜, 접이 검색, 모임/정모 구분은 이미 존재. 더 많은 분류보다 특정 정모 카드 클릭 맥락을 먼저 개선하는 것이 체감효과 큼.
- **모임 홈**: 전체 채팅과 번개·정모를 같은 공간 안에서 찾을 수 있음. 일반 모임에 여행 생성이나 동선 편집을 기본 강요하는 현재 코드는 확인되지 않음.
- **채팅**: 보낼 내용·답장 미리보기·스티커 선택의 명시 전송은 적절. 메시지마다 ‘답장/반응/더보기’ 한 줄이 반복되어 긴 대화의 세로 길이가 길어지지만, 숨김 방식 전환은 학습·발견성 손해도 있으므로 P2. 기본 기능 삭제 없이 길게 누르기나 펼침 동작을 보조 방식으로 검토.
- **계정**: 로그인/회원가입 방법 선택과 약관·정보/이메일 인증 구분은 요청에 부합. 비밀번호 보기 토글은 현재 코드에 없으므로, 가입 입력 오류 감소 목적의 작은 추가 제안 가능. 자동 입력·자동완성 속성은 이미 있음.

우선순위: 입력 초안 보존과 종류 오표기 → 작성 모드의 작은 조작 개선 → 저장 검색과 특정 정모 맥락. 기존 화면 재설계나 메뉴 증설은 현재 근거만으로 권장하지 않음.
