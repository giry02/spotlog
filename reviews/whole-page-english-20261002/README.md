## 백업 범위

`change.patch`는 이번에 변경한 소스 7개의 수정 전/후 차이만 포함. `manifest.json`은 각 파일의 UTF-8/LF 기준 해시. `ui-results.json`과 `integration-results.json`은 검수 결과.

- `web/src/TranslationText.tsx`: 전체 언어 설정에 따라 자동 표시, 화면 단위 상태·재시도, 취소된 응답 차단.
- `web/src/App.tsx`: 여행기 언어 선택, 본문·제목·장소 소개·댓글 표시 연결.
- `web/src/PublicTourismCredit.tsx`, `JournalPhotos.tsx`: 원래 사진 설명 자리에서 전환, 중복 번역 제거. 출처 유지.
- `web/src/CardSocial.tsx`: 댓글 팝업 전체 언어 선택과 댓글 표시.
- `web/src/TravelGuideSheet.tsx`, `travel-guide.css`: 기존 언어 선택과 안내 연결, 문맥별 스타일 유지.
